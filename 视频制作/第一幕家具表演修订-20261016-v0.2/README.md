## 已落实的表演

- 床：知夏后仰时枕头鼓起托背、被缘整理、床头日出提示；她点头躺回后枕头放低、被子自己盖好。
- 衣柜：衣架递出既有便服，门面显示搭配线稿和“昨晚选好”，等她回应。未新增服装定款。
- 拖鞋：先到位、等待、再微调对齐，鞋口撑开。
- 杯托：对知夏转头产生迟疑，再小心靠近一点；杯托光纹提示水温。
- 全息窗：园景中局部展开水巷实时借景，播报同时有可见内容。
- 喊停：衣架轻晃后稳住、杯托保持原位、显示退去、窗恢复园景；枕头继续承托。停止服务不是掉电。

其中床、衣柜、盖被已提供新关键图；拖鞋、杯托、窗与停止过程在动作稿中更新，复用既有造型参考。静帧不等于动态演示，自主运动需要实际视频验证。
