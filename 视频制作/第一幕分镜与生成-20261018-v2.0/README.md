## 使用与维护

最新准入结论见[生成前终审](生成前终审-20261018.md)：可进入短镜试验，尚不可原样全量提交。下方工作台实现检查通过不等于生产准入；现场模型规格另存证据JSON。

默认看故事总览，再看带关键帧的镜头卡。每镜按摄影、动作表演、对白声音三栏阅读，底部交代起止和下一镜。多状态图并排，不重复主图；总体限制和逐帧限制均保留。母版、参考、完整动作、光线与检查项可展开。点击镜头卡的批次链接进入生成执行，点击批次中的镜号返回分镜。

生成视图展示批次、参考图用途、节拍和余量、完整提示词、真实执行及采用记录。当前记录为空，页面不提交请求。模型时长上限与参考槽位沿用历史规划，实际执行前须现场核实。

只维护atlas.json中的镜头事实，以及plan.json中的镜号分组和执行配置；后者不再复制动作/对白/图像/时长。HTML、resolved-plan.json和prompt-G*.txt均为派生输出，更新源数据后重新运行：

```powershell
python .agents/skills/linzhixia-keyframe-atlas/scripts/build_atlas.py --root . --manifest 视频制作/第一幕分镜与生成-20261018-v2.0/atlas.json --plan 视频制作/第一幕分镜与生成-20261018-v2.0/plan.json --output 视频制作/第一幕分镜与生成-20261018-v2.0/分镜与生成.html
```

页面是生成后的阅读交接册，不含在线编辑或自动保存。migrate_v19.py仅用于首次迁移，新目录内源文件存在时会拒绝覆盖；以后直接维护当前atlas/plan，不重复执行迁移。

准备实际提交时，可在同一命令加`--snapshot-unit G05 --snapshot-dir 项目内未存在的目录`，只冻结prepared输入，不提交。它复制参考文件并记录哈希、提示词、镜头和规划参数；随后按实际请求记录端点与槽位。已提交输入不随新分镜重建。
