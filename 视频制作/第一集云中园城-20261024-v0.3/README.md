## 颜色及云的处理

黛青瓦与深青窗负责轮廓，暖粉墙和青灰石建立大面积基底，熟木及局部赭红木增加生活温度。青碧水、松绿和新叶绿分别承担水体与植物；桂黄集中在少数中庭/东侧庭院树群，不平均撒到每栋建筑。

具体色块是本轮设计的sRGB输入，已计算转换为线性材质值，写在 `color-cloud-plan.json`；并非参考图取样或历史园林标准色。对象绑定清单也在该文件。更完整的设计关系见[色彩与云层规划](../../第一季/制作/空间规划/第一集云中园城-v0.3/色彩与云层规划.md)。

云用固定世界空间的厚薄变化和庭院空气区来形成近清远隐，不使用跟随相机的清雾球。较厚云的暗部保持冷青灰、亮部接近中性白。日光方向和显示对比帮助区分瓦面、墙面和檐下；没有全局提高画面饱和度。

城市外部以独立材质副本和对象级绑定改色；原非云材质本身、学校水墨、家/作坊室内的本色保持。全局日光与显示设置仍会改变它们的受光外观，此点与本色保护区分。

## 检查与边界

`review-v05.md` 为独立静帧审查；`independent-audit.json` 为几何、动画、原材质及允许绑定清单的只读核验；`media-validation.json` 记录完整帧序与三条视频解码。全程及水庭段联系表、最终视觉记录分别保存，不把抽帧当作实时连续播放验收。

`render-only-batched-v05.blend` 是渲染副本，保留对象级色彩绑定及局部纹理坐标。两个同机位源工程对照的平均通道差小于0.051/255，见 `proxy-image-comparison.json`；这是抽样一致性检查，不是完全逐像素相同。

`trial-a-dark-cloud.blend` 和 `trial-a-preview` 是本轮偏褐、偏暗的拒绝试验，不能混作当前候选。当前云仍有参考级细条纹/颗粒，部分云下空面较大，水纹和树形非最终细节；最终采用由作者观看决定。

所有成果留本项目。渲染和打包脚本在 `第一季/制作/空间规划/第一集云中园城-v0.3`；项目现有Git规则排除生成图片/视频，媒体在本地项目保存，工程、脚本与检查记录提交Git。
