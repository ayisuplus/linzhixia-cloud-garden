# 第一集水巷街桥 v09

作者指出 v08 单调、开头独立圆环像跳圈、房屋与水关系松散。本轮在原连续山水地形上重新组织沿线街屋、桥与相机，保留旧版和原采用素材。

## 看什么

- [完整58秒](waterlane-flight-58s-v09.mp4)，[图文入口](review.html)。九座跨水桥、二十段临水街屋；开头圆环与支柱撤除。
- 学园檐廊街、水湾桥头、下游作坊水巷三段生活片段。部分底层设店屋，公共岸路从檐下经过，原横向院门通路留空。桥连两岸路口，廊桥只在两个节点使用。
- 飞行从檐廊起步，经山肩与云谷，进入水湾后靠岸穿街屋，再展开水面；最后出水巷、过桥、贴水并抬升到作坊。不是九桥逐一穿越。
- 黛青瓦、暖墙、青碧水、木色和少量赭红沿用原材料。未重新配色。云仍从侧方与上方围合，近处生活面留清楚。

## 文件与复现

- `waterlane-masterplan-v09.blend`：可编辑静态场景。
- `waterlane-route-58s-v09.blend`：含1392帧相机，24fps。默认隐藏云，便于几何检查；视频启用云。
- `batch-A-00-30.mp4` / `batch-B-28-58.mp4`：两条30秒参考片，重叠2秒。
- 源脚本在 `第一季/制作/空间规划/第一集水巷街桥-v0.1`。`build.py` 读取 v08 最终总图，复用旧版纯坐标模块；不会重建或覆盖旧地形。依次运行 build、flight、render_views、render_flight full、package，均以项目根目录为参数。
- 基础材质及地形来源为 v08。新增颜色仅恢复其文件中未持久保存的原 CITY05 松绿，不改变已定色族。

## 验证边界

`route-check.json` 是1392帧路径以及1.1×1.1×0.7米载体的27偏移点逐段射线扫掠结果，不等于精确连续实体或真实无人机动力学。固定58秒重新分配速度；最大速度约61.5m/s，属于动画参考。

`video-validation.json` 记录PNG、时长、帧数和三条MP4完整解码。抽帧与独立检查结果见 `final-review.md` 及本目录独立报告。没有把抽帧审看写成已实时连续播放。

仍为布局参考：远区旧院落有重复、山体和云表面简化、植物只为体量节奏；街屋上层楼梯/室内未细化，桥梁未做结构计算。候选未自动升为正式采用，未调用云端生成。
