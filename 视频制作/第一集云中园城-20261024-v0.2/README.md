# 云内园城 · 下层水庭显露与58秒复飞

本轮沿作者要求，调开遮住下层水庭的局部云层，保留城市在巨云内部的关系。原v0.1与所有历史工程保留；本版仍为参考候选。

## 观看与编辑

- `review.html`：完整试飞、时间跳转及旧新对照。
- `cloud-city-full-flight-58s-v04.mp4`：58秒、24fps、960×540、1392个原生渲染帧，静音预演，无插帧或变速。
- `cloud-city-water-reveal-58s-v04.blend`：保留完整对象结构、原建筑材质和可编辑时间线。
- `打开云中园城v04.cmd`：从文件管理器双击，用本机 `D:\blender\blender.exe` 打开工程。
- `B01-cloud-city-0-30s.mp4` 与 `B02-cloud-city-28-58s.mp4`：两条30秒参考片，重叠2秒；未上传或提交视频生成服务。

## 这次修改

对叠水庭院、中层庭院和东侧下层水庭设置局部羽化空气开口，同时减弱下方承托云的过强补光。云的上部和侧部继续围合，开口外密度保持；没有整体清空云海或改变建筑配色。

原镜头经过叠水庭院时向上看，下层水面落到画面之外。因此在10.8—19.8秒增加平滑的短暂俯视，最大额外向下21度，随后回到原朝向；摄影机位置、无人机载体轨迹、三次穿窗位置、末段贴水及58秒总长保留。

## 渲染与检查

`render-only-batched-v04.blend` 是仅供渲染的派生文件：将静态建筑网格按材质组合合并，并用属性保存原局部/Generated纹理坐标，保留独立云体和动态载体。它不替代可编辑工程。五个同机位对照（含起终帧）的平均通道差均小于0.43/255；报告在 `proxy-image-comparison.json`，这是抽样图像对照，不是逐像素完全一致保证。

检查记录：`review-v04.md` 是独立静帧评审；`independent-audit.json` 是原资产与逐帧运动对照；`media-validation.json` 是所有帧及三条视频的结构/解码检查。全程及水庭段联系表与实际观看记录另存。视觉、结构和播放舒适度的结论分别记录，不互相替代。

下层水面与落水边已经能读出，但部分时刻仍位于画面下缘，完整亭台与瀑布未同时全露；局部灰白空面及云纹理仍是参考级。最终采用以作者观看为准。

脚本位于 `第一季/制作/空间规划/第一集云中园城-v0.2`，依次执行 `build_revision.py`、`build_render_proxy.py`、`render.py --full --file render-only-batched-v04.blend --output frames` 与 `package.py`；参数均以项目根目录为准。媒体按项目现有Git规则保存在本地项目，源码、工程与检查记录提交Git。
