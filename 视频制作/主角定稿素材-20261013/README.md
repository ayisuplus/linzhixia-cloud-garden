## 使用顺序

服装结构先看00定款原图，再看01四视图、02穿搭、03妆造；人物面容独立以便服07为准，其他图板尚待校正；04—07是总图原像素裁切。面容主参考不代表便服07的旧配件仍采用。来源与完整提示词位于各分类的“来源与提示词.md”。

- 保持已定配色、材质和年龄观感；全角色取消腿部皮肤云纹。便服保留双白袜长短不同的定款。
- 校服采用水墨长衫与暖白布靴，原蓝白短裙仅作历史。
- 工作服衣装为水彩与抽象泼墨、袜纹简约、鞋面花叶刺绣；不恢复具象山水、密袜纹或鞋面泼墨。
- 三件套中的侧背、隐藏结构及完整单品仍属于设计补全，不是实测正交图或纸样。局部纹样、发丝有生成差异，以定款原图优先；工作服素木簪以原图和妆造板为准。
