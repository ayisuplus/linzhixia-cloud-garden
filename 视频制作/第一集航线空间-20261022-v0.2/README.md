## 本版变化

- 学校及对应校内机位整体平移 **(-1350, +900, +36)米**；原卧室、起居室、作坊、宿舍与舞室内部布局保留。住家与作坊仍隔水相对。
- 移除新副本中的旧近邻学校坡道，旧v0.1文件原样保留。旧版不再代表本集跨区布局。
- 同一包裹的路线为：宿舍寄件→学生园居与水庭→相邻学习庭院→校园外缘→叠水薄雾→上层园城→中层街区→下层园院→长水巷→作坊檐下收件位。
- 飞行折线约 **1803米**，拟定步行路线约 **2422米**。这是本轮布局的模型距离，不是已采用的世界观尺度，也不把步行可能性抹去；寄送免去往返跨街区取送。
- 沿途增加 **173个建筑体块**，含学习庭院、远景占位、三片园城及水巷住宅。新增建筑只确定位置、体积、高度和街区层次，没有精雕立面或室内。
- 新增9个沿途/总览机位，并保留原场景机位；总览橙线仅为审阅标记，场景内无实体航道。Blender视口可见全程路线曲线和8个路标。

## 原美术与空间边界

学校本体维持水墨方向，宿舍私人空间暖色；城市使用原暖灰、木色与低饱和绿的简化体块。薄雾只是可撤销视觉接口，不确定传送机制。大底板仅作尺度展示，不改写移动云城的设定。道路、支路、地形和桥梁是拍摄粗模，不是规划或施工成果。

各场景仍处于同一个可编辑工程。没有用只给镜头看的面片代替中段建筑，也没有为了单张构图拆掉原房间墙体。已有A/B/D/E/F/G内部空间继续复用，C段现在有真实展开的路程。

## 检查与限制

- 从保存的`.blend`重新读取，包裹全程3642个离散位置、跨区步行9755个离散位置均零障碍命中、零地面缺口。
- 飞行按≤0.5米间距取27条外廓偏移射线；步行按≤0.25米间距取半径0.25米、三档身体高度射线及向下地面探测。它们不等于连续体积碰撞或最终游戏导航。
- 起点仍命中宿舍寄件栖架，终点命中作坊收件栖架，货舱底约2毫米间隙；源v0.1文件SHA-256未变。
- 修正了叠水旁道路穿台体、坡道转角覆盖、支柱顶干扰地面及回家路树冠阻挡。新增支路并未全部做人物导航验收，粗建筑内部未做可进入设计。
- 地面重合黑斑通过可撤销的3—16.8毫米石地表面错层修正；原网格数据与房间布局不变，检查使用加修改器后的实际几何。
- **旧10秒路径动画已移除。** 本版路线未绑定正式时长，不能把约1.8公里当成10秒实际飞行；C段既有分组时长仍是待测预算，可用切镜组织真实行程，不在本轮擅改。
- 全息、角色、运送器最终造型、最终美术和连续动态摄影机尚未制作。当前重点是空间覆盖和距离成立。
