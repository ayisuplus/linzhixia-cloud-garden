## 01 日常练功

![日常练功](舞蹈室01-日常练功.png)

左侧镜墙与把杆，前景入口收纳和坐凳，中央连续木质练习地面，右侧临水长窗与外廊，远端保留实体门和水墨界面。室外天空、树木、山与水全部延续水墨书院。

练习区完整、柱退在边缘，镜墙能识别出对面窗景与室内结构，提供舞蹈教学用途。镜面反射仅作目视检查，未按三维几何验证。地板反光比预期强，应在后续材质细化时收柔。把杆为可见固定支座式外观，收纳机构没有具体呈现；活动遮镜屏的轨道、板片结构同样待细化。

## 02 荷塘仿真

![荷塘仿真](舞蹈室02-荷塘仿真.png)

直接编辑01：左侧镜墙被场景界面覆盖、把杆收起，左墙、远墙和右侧较远窗格呈现彩色荷塘，最近一扇窗外仍然是原有水墨校园。木地板边缘出现水纹光影，中央仍是实体练习地面。

这张较好地保留了机位、梁架、灯具、后门、窗框、栏杆和前景坐凳收纳的主要位置关系，便于比较。属于目视连续性检查，不声称像素锁定；环境光与细节有重绘。

目前彩色荷塘仍像环绕墙面的绘景，左侧荷花尺度偏大，与远墙景色的连续透视还不足以支撑“身在荷塘”的效果。水纹在墙脚边缘较亮，但没有将中央地板变成真实水池。保留为切换概念首稿，不称为已验证的全息沉浸系统。两张静态图没有证明镜墙遮蔽、把杆收纳、场景过渡、多人视差或动作响应。
