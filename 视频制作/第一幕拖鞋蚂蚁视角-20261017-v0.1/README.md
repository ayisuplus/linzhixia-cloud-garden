实际可见：贴地低机位中，两只空拖鞋前后错开，鞋跟开口朝向镜头、鞋头朝向前方地垫；近鞋后跟略抬。床沿和垂下的被角在左上方，木地板与地垫边缘形成明确的行进路径。青绿鞋面、奶油包边及粉白荷花装饰保留，没有新增肢体或脚。

视频计划：镜头几乎贴着木地板，从后侧跟随两只拖鞋一前一后朝床沿走。鞋底轻微弯曲，晨光与窗影掠过鞋面；到地垫边缘时镜头稍抬，见垂下的被角，拖鞋准备转向并排。不钻入床底深处。
