## 本轮实际变化

旧40组同尺度散置庭院隐藏，新增10组有主侧屋和院墙的附院，与原命名庭院一起组织疏密。新增6处水庭，外部54组屋顶采用统一曲面与檐口语汇；柱廊补断面与梁，三道圆窗墙接侧墙，植物与园石围绕庭院、水岸布置。地面路径按实际墙体、水池和树干绕行。学校旁10个旧尖锥远山占位隐藏，避免误读成正式尖塔。

学院维持既有黑白灰，游园和水巷沿用灰瓦、暖木、米墙、青绿水与植物色族。48个原材质不改参数，原始场景对象不删除；被隐藏的旧对象逐一登记于`design-audit.json`。新物件是建模候选，不替代原室内、服装、人物或采用美术。

飞行位置采用五次圆角与按曲率分配的速度，相机跟随真实前进方向。按24fps位置二阶差分计算，全程最大平移加速度约42.64m/s²；旧片约9.9秒紧弯处约230.8m/s²。相机最大相邻帧转角约3.403°，并不是旧片的2.323°；此次重点是去掉急折位置和镜头之间的横滑矛盾。数值是预演参数，不是实机飞行性能承诺。

约14.95、26.42、44.10秒穿过A/B/C窗洞，48.26秒进入贴水段，54.64秒附近开始抬升。收件前最后两秒先向东让开门廊柱，再接原终点；总时长、前段位置及两批30秒结构保留。

## 检查与证据

`review/independent-diagnosis.md`保留旧版“发卡”的定量诊断；`design-geometry-check.json`、`roof-check.json`与`final-freeze-review.md`记录设计复核。早期失败和修正前报告保留，不能将`before-fixes`或`before-tail`当作最终结论。动画安全性以最终尾段复核为准；粗27点包络检查曾漏过细门柱，因此不能以粗检代替加密结果。

`review/encoding-check.json`记录实际编码参数和完整解码结果，`delivery-manifest.json`记录交付文件大小与哈希。尾段复用/重渲染范围见最终审查记录；没有使用插帧或调整播放器速度。

静态对照与密集抽帧用于核对空间、遮挡、过孔和低飞；没有将抽帧等同连续播放舒适度已获采用。现阶段仍是给视频模型的空间参考，云光、树叶、微材质、水流和最终风格细节未作为成片验收，也未提交生成模型。局部道路离散检查不是全城导航或工程安全认证。

给生成模型使用时，采用美术图继续负责最终颜色与材质；本片负责空间、机位和大体轮廓。不能把低清Eevee的灰淡光照当成全片去饱和要求。
