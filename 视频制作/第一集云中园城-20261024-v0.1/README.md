# 一朵云里的城市 · v03 空间候选

依据2026-10-24作者纠正：整座城市包在一朵巨云内部。此目录是当前施工候选，替代上一轮“云底座上摆城市”的构图，尚未标为最终采用。

## 工程

- `city-within-cloud-reference-v03.blend`：参考预览工程，保留24fps / 1392帧 / 58秒时间线；近似体积补光帮助阅读云与建筑。
- `city-within-cloud-58s-v03.blend`：Cycles空间版本。上方、两侧包围云，庭院空气区和天光开口，六处局部侧云；内部承托云保持单连通。
- `打开云中园城.cmd`：在文件管理器双击可启动本机 Blender。聊天或浏览器的 `.blend` 链接不保证启动外部程序。

原建筑语汇、材料色族、起终点、三窗与末段贴水保留。过窗约10.21、20.58、42.67秒。0—30秒与28—58秒两个生成批次的关系保持；未上传或提交视频生成服务。

- 原路线经过实际网格的27条采样包络射线检查；保存后的摄影机1392帧中心线已复查，含收件处改写，无命中。相邻巨云试验目录保留原报告。
- v03仅从承托云中减去侵入生活面上方的体积，未新增实体障碍；`support-refinement.json`记录单连通、严格减体积，`support-clearance-v03.json`重查1392×27采样未入承托云。场数值不是米制净空。
