## 定款保持关系

- 采用05的清秀面容、发型、青春CG表现和腿部比例，不返回面容01的偏圆脸。
- 短衫两侧明确收腰，沿用自然腰线高度及略短裙摆；短衫与裙腰相接，不在裙子上方叠出外张下摆。
- 人物右侧衣襟与三枚小盘扣，胸前素白，保留蓝色领袖边；不改为居中大盘扣。
- 双鞋背的小簇蓝白花叶绣与侧边流线绣配套；人物右小腿云纹及鞋内袜、左腿膝下袜。
- 人物右低髻白栀子、左顶部浅弧发夹；左腕饰品、右腰小终端；水杯挂书包右侧。
