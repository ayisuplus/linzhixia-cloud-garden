# 独立园岛 v16 · 空间规划候选

本轮依据作者对独立园岛与高低跨岛水流的澄清，重新搭建第一集沿线总图。连续地形、长河和旧逐帧航线退出约束；原工程及已采用素材保留。七个单元、九组复用院落、三道跨岛跌水、七条桥廊及换层亭，是规划白模而非最终园林美术。

桥面从塔南侧平台接入，塔内折返楼梯与预留升降井承担高差；院内路与桥口局部约14cm高差按有阶参考，非无障碍认证。水池、出水唇、自由落水和下池均建几何；水流、云质支撑及电梯没有运行模拟。内路及桥口是几何候选，不等于全城可玩导航或建筑可用验收。

58秒保留为时长预算，规划数据与图中仅有飞行走廊草案。未复用v15相机，未录制新58秒视频，未调用外部生成。五张Blender静帧与两张程序绘制关系图承担本轮展示。

原工程路径：`../第一集枝水园城-20261024-v0.1/branch-garden-route-58s-v15.blend`。当前工程在Blender 5.1.0中建立；若聊天链接不能启动软件，请从Blender的“文件 → 打开”选择本目录的`.blend`文件。它不依赖同目录图片材质或联网服务。

脚本依赖前版`geometry.py`基础几何函数和v15工程，源文件路径写明在build.py；重建为版本化候选，不能覆盖旧工程。脚本顶层执行均使用显式项目根目录。
