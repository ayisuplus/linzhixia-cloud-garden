# 第一集园城航线重排 · 58秒候选

作者反馈：上版仍然空，转向意图不清，部分进近像要撞墙。这一轮同时调整通行方向、沿线空间与镜头；上版保留作比较，不再把“采样没有碰撞”当成视觉通过。

## 打开

- `garden-city-flight-58s-v04.mp4`：完整58秒参考视频。
- `review.html`：视频、穿窗时间入口和实际渲染抽帧。
- `garden-city-flight-58s-v04.blend`：可编辑场景及新时间线。
- `garden-city-space-v01.blend`：空间候选，未包含本轮新时间线；看飞行请用上一项。

## 具体改变

1. A、B景墙围绕原圆孔中心旋转，与航线对齐。删掉上版绕墙遗留折点，提前进入直线进近，穿窗后继续向前展开。孔中心与半径保留。C窗保留原朝向，在到达墙前完成对准。
2. 起点从实际廊下空间出去，再沿一个方向爬升出校；不再先向北绕屋顶、再突然朝南折回。相机采用前方空间作为视线目标，限制抬头幅度，避免爬升时整屏只剩天空。
3. 中段从院落附近穿行，减少高处远眺空岛。新增院落采用主厅、较低侧屋、前院、围墙和外围小路；以不同大小的组团代替独立房子散放。
4. 新增70组院落、189处树丛的初稿经过独立复核，收掉岸外2组院落和6处树丛；最终本轮新增可见68组院落、183处树丛。另有8栋水巷街屋，补石砌台基接到低3.465—3.5米的云岸，南岸主要立面朝水。院内树石从东厢房退到前中院。
5. 岛间的云隙继续留空，岛上补建筑、植被与道路的近中远层次。保留原三次穿窗、末段贴水、过桥与原收件位置；58秒不变。
6. 最后2.2秒相机在收件台前收稳，看向接收位置，无人机继续到原终点。该段是观察机位，不是刚性固定在无人机上的第一视角；避免镜头最后贴向白墙。

既有材质配色保持，学校黑白灰、游园灰瓦暖木与青绿、水巷暖墙木构的分区沿用。原人物、室内、采用美术和旧工程没有被替换。此轮没有调用视频生成模型。

## 节奏与批次

24fps，1392原生帧，58秒。A约10.29秒、B约20.54秒、C约42.63秒穿窗。保留两段30秒输入：B01为0—30秒；B02为28—58秒，重叠2秒。

`flight-checks.json` 保存逐帧机位、前视方向、路径与窗口交点；数值用于动画预演，不是无人机物理性能认证。最后相机调整后的检查以独立最终报告为准。

## 复现与范围

脚本位于 `第一季/制作/空间规划/第一集园城航线重排-v0.1/`。运行顺序：`build_space.py` → `build_route.py` → `finish_arrival.py` → `fix_support.py`。前两项接收 `--root`，后两项在 Blender 的 `--` 后接项目绝对路径。完整动画直接渲染可编辑工程，沿用 `第一集全程快飞-v0.1/render_preview.py` 的动画模式。源工程与旧候选保留；`refine_court_planting.py` 和 `refine_podiums.py` 是制作中的局部修复记录，重新运行主链已直接包含这些修复。

本版仍是参考级场景，细材质、植被形态、水流、人物活动与正式成片尚未制作。抽帧、路径采样、静态几何检查分别记录；作者观看后的节奏和审美判断优先，不把技术检查替代观看验收。
