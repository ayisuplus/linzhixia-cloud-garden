2026-10-15｜**概念候选，待作者审看。** 作者要求展开智能家具、会说话的床、全息窗及可定制房间场景；本轮用一张起居室图呈现夜海观星模式，并另存[智能家居与储物设计提案](../../世界观/生活技术-智能家居与储物-设计提案-v0.1.md)。床的完整形态留给卧室，起居室用可坐可躺的坐榻承接休息场景。

## 本图怎么读

- **左侧全息窗**显示虚拟海天，墙顶延伸星光与水影，形成一个可以选择的环境模式。不是从家中开门走到海边。
- **右侧真实开口**看见院内池庭、花木与廊屋；真实园林继续提供空间参照。起居室位于生活园，作坊仍在园外水巷对岸。
- **近处智能坐榻**表现为柔软躺坐姿态、局部脚托和提示灯；拟议软硬变化、调姿及语音回应不由静态图证明。
- **中央茶几与茶托**提出随使用调节高度、托盘送到手边的便利。实际图中茶托仍像有实体支撑的升起托盘，悬浮间隙不明确，后续需单独设计。
- **展示柜**保留真实书、陶器与收藏，收纳展示成为偏好。**左下镯子托座**是储物镯的外形占位，不等于改动知夏已采用玉镯的身份或确定储物机制。

## 设计与边界

家具可语音交互，房间可在日常、学习、观星和安静休息之间切换。说话的床、可展开界面、声光联动等其他设想见上方提案，不把图中没出现或静态图无法证明的动作算作已完成。

实际查看：海天窗与池庭同时可读，影像集中在窗、墙顶，地面和实体家具保持可辨；室内暖光与虚景冷色平衡，原生材质仍有明显中式园居气质。星图只为场景装饰，未作真实天文星位校验。

待讨论：投影覆盖的面积与强度、坐榻和茶几更鲜明的可变结构、茶托的悬浮表达、投影关闭时房间的样貌。开口处有较厚收边，通路净宽、门槛高差与身体活动仍待模型核查；本图不是已验证的无障碍或工程布局。储物容量、重量、一键穿戴与实景视点权限仍未定案，不把助手上轮建议视作作者已接受的规则。
