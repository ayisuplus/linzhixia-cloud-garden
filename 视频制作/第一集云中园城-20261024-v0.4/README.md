# 云内园城 v06 · 云下层次

在作者认可v05色彩后，局部细化下层灰白空面。保留同一58秒航线、水庭显露、近景建筑和包云方向；旧版本不覆盖。

- `review.html`：完整58秒视频和四组同机位旧新对照。
- `cloud-city-layered-flight-58s-v06.mp4`：960×540、24fps、1392个原生帧，58秒静音空间参考，无插帧/变速。

## 本轮修改

只修改 `MOTHER CLOUD connected supporting cloud` 与 `ENCLOSING CLOUD with open courtyards` 两个材质。固定世界空间的宽尺度疏密配合起伏密度顶面，让原下部连续灰白云出现云脊与通透凹处；低处补光随结构调整。新密度乘数限制在0—1，既有庭院空气区仍在上游；从-15米至75米逐渐恢复原云输出。没有添加跟着相机跑的云洞。

不改已认可的城市材质色块、灯光、世界背景、显示变换、建筑几何、物体绑定和动作。独立审计逐项核对，不把材质保存成功当作视觉效果通过。

详见[设计说明](../../第一季/制作/空间规划/第一集云中园城-v0.4/设计说明.md)。上一版[色彩规划](../第一集云中园城-20261024-v0.3/review.html)继续沿用。
