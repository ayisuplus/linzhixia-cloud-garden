# 云山聚落 v11

这版把山谷散置树石重排为依山的露岩、松竹群落和三处错层山居。六栋房子采用前侧挑台与落地柱架、后侧石基，沿用现有灰瓦、粉墙和木色。旧版及采用素材保留。

## 文件

- `cloud-hamlet-flight-58s-v11.mp4`：完整航线，960×540、24fps、58秒、无声。
- `batch-A-00-30.mp4` / `batch-B-28-58.mp4`：两条30秒参考片，中间重叠2秒，便于后续生成衔接。
- `cloud-hamlet-masterplan-v11.blend`：可编辑静态场景。
- `cloud-hamlet-route-58s-v11.blend`：可编辑场景及1392帧相机动作。
- `hamlet-1/2/3.png`：三处山居斜视图；`valley-contact.jpg`与`flight-contact-sheet.jpg`用于抽帧检查。
- `landscape-data.json`：新增山居、柱脚、阶梯、植物与地形改动记录；`manifest.json`记录交付哈希。
- `audit.md` / `audit.json`：独立CPU几何审查；`final-review.md`记录交付与视觉边界。

聊天中的工程链接不一定自动启动Blender。可在Blender中“文件→打开”，进入本目录，选择上面的`cloud-hamlet-route-58s-v11.blend`。打开后相机时间线为1—1392帧，24fps；云层默认可渲染。

## 改动范围

撤下v10的1098个零散树石对象。在原连续山体局部调整13576个顶点，保持原道路、建筑及其保护区；六条低凸岩床的周缘入地，坡面颜色连续过渡。48株松、36丛竹、252处低灌丛沿缓坡及宅旁分布。增加三处山肩薄云，原35个围合云体保留。

三组共六栋山居与六条石阶通路相接。柱根和阶梯底部按最终地形落地，入户是真实开口。六栋数量、造型及其位置均为本轮可编辑候选，并未升为采用资产。

路线逐帧沿用v10，58秒时长与末段柱距修正保持一致。近处楼、树、水街清晰，山体仍为简化云质体块；岩面细节、植物叶簇及完整建筑细部尚未完成。三处岸路入口还有约6.7—8.3cm收口高差；此为拍摄/生成参考，不是施工或可玩建筑认证。

## 复现

脚本入口：`第一季/制作/空间规划/第一集云山聚落-v0.1`。使用本机Blender5.1，按`build.py`→`render_overviews.py`→`render_flight.py full`→`package.py`执行。前三个Blender脚本通过`--`传项目根目录；渲染另传`preview`或`full`。打包使用本机Python、Pillow与ffmpeg。

完整逐帧PNG放`frames`中用于本地加工，未加入Git；保留MP4、关键预览与可编辑工程。不调用外部模型或生成服务。
