本版补齐水墨校园的寄件起点、山居上下层接驳、双高度云舟码头、半园住家与对岸作坊的用途差异；谷肩局部开隙，原云层围合、主水脉与城市色族延续。详见[设计与施工说明](../../第一季/制作/空间规划/第一集云城校准-v0.1/设计与施工说明.md)。旧 v11 保留。

Blender 中使用“文件 → 打开”，选择本目录 `cloud-city-route-58s-v12.blend`。聊天链接是否唤起 Blender 取决于系统关联；可直接在 Blender 内打开。时间线为 1—1392 帧、24 fps，活动相机已绑定；数字键盘 0 查看摄影机。

视频为 960×540、24fps，无声。两条参考批次为 [0—30秒](batch-A-00-30.mp4) 和 [28—58秒](batch-B-28-58.mp4)，重叠2秒，拼接去重后58秒。不是两段各自延长的剧情。

## 六处主要变化

1. 校园外部水墨分区，宿舍私密内墙保留暖色；廊外寄件台接入岸路。
2. 谷肩局部削低开隙、薄云包边，原岩床随地形调整，避免悬浮表层。
3. 三组山居共享升降接驳与上下廊道，原石阶继续保留。
4. 双高度码头与静态云舟，作为前后复见的同一地标。
5. 半园住家补池、种植与坐凳；作坊门侧补工作台、木料和收件台。
6. 少量云根植物与清水循环节点，表达未来生态/日常用途，形态仍为候选。

## 证据与限制

[独立几何审计](audit.md)及首三轮失败记录保留；冻结哈希、实际图像与视频检查分别见 `manifest.json`、`video-validation.json`。渲染网格合并只在内存进行；三个机位与未合并图对比误差记录在 `render-batching-probe.json`，可编辑工程不合并。

本版为参考精度，云坡局部仍较硬，水墨尚未精修笔触，远景云根形态较弱。升降轿厢、云舟、水循环节点均未模拟运行。有限几何采样不等于完整游戏碰撞或建筑认证；未改原采用图册、未提交外部生成。
