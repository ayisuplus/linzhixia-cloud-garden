## 制作与复现

源脚本在 `第一季/制作/空间规划/第一集山谷植物-v0.1`。Blender 5.1 依次运行 build.py、flight.py、render_flight.py preview/full；命令 `--` 后传本项目绝对路径，渲染脚本再传模式。package.py 使用普通Python，传项目根路径，需numpy/Pillow及ffmpeg。

build.py 读取v09静态场景，复用v08坐标模块和v09网格函数，固定随机种子241024。新增77处山石、50株松、24丛竹、157团低灌木、10片贴地覆盖。石底圈逐点埋入实际地形，植被避开原路、建筑和飞行通道。松、竹与石形是本轮参考设计，不是新物种正式设定。

原材料不变；石材恢复此前白模预设灰绿，地被采用现有叶绿与地形颜色的混合，未对既有场景重新调色。植物和石面仍属参考精度。

静态工程默认关闭独立云集合以利检查，视频启用云。两个30秒参考批次为0—30、28—58秒，重叠2秒；没有提交生成服务。

## 检查范围

独立比较2234个旧对象与原材质，未发现改动；新增物对旧路、建筑和航线的有限扫掠检查通过。末段实际柱面距离约8.13米，旧版49.8秒附近窗口最小约2.37米。距离指相机中心，扣载体外接半径和采样余量后的保守值约7.23米；非飞行动力学认证。

已完成1392张PNG及三条视频解码检查，见 video-validation.json。已审看全程联系表和重点近景；未把抽帧检查当作实时连续播放验收。前段两处保留的檐廊仍为近建筑飞行，不把末段8.13米写成全程最小距离。
