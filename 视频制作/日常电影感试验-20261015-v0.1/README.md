# 日常电影感试验：清晨、旧物与归家

2026-10-15｜作者同意先尝试光影、构图与日常情绪的方法。3张主候选、1张旧鞋修正前历史图，内置imagegen共4次调用。全部待审，不替换现有角色、场景或全片美术。

## 本轮尝试的范围

上一轮讨论以新海诚的日常观察、背景与情绪关系为学习对象。本轮将方向拆解成可比较的镜头选择：光的主次、生活细节、景别、前景遮挡和注意力落点。保留现有写实风格化CG表现，没有进行全片二维动画化或角色改型。

卧室与水巷编辑沿用原机位的主体关系，便于看光影改变；旧鞋是新近景，未有对应原镜头，因此不能将三张称为严格单变量实验。暮色单独改变时段，不据此把第一集收件时间改到傍晚。

## 01 清晨卧室

![清晨卧室](01-清晨卧室-光影试验.png)

直接编辑既有卧室人物合景03，保留床、窗左衣柜、窗下矮书架、窗右书桌及右廊洗漱处。背景光比更克制，人物脸旁枕头与汤圆仍明亮，屋内阴影更冷、更安静。

目视主要布局、人物姿态及服装色族保持；面容、衣纹、汤圆细节未经逐像素核对，不替代人物母版。原图的蜷腿姿态仍保留，其姿态待审状态没有因这次调光自动解除。窗与地毯依然有较强亮度，视线还不完全由人物主导。这张变化较温和，尚不足以证明美术方向整体改变。

## 02 旧舞鞋桌面

![旧舞鞋近景](02-旧舞鞋-桌面近景试验.png)

以已认可作坊室内作环境参考、安清意当前采用主图只提供鞋型依据，重新生成桌面近景。保留暖米色柔软布面、包趾包跟、薄软平底、无扣无横带；无人物和袜子。布褶、织物与磨损成为主信息，背景抽屉和工具虚化。

原02a破口过于醒目，右上角还有淡色图形杂点。随后以02a直接编辑，破口缩小到近鞋底边缘；右上杂点仍隐约可见，清理未完全成功。02b作为较轻磨损候选保存，02a留历史，不声称已可直接用作最终镜头。新图工具呈尖锥形，与提示中的钝木工具不一致，不据此确立维修工序。

近景使旧物本身更易被注意，但摆放仍偏整齐，光线仍较均匀，尚有静物产品照感。后续实际分镜可加入接鞋、翻看等动作。家传旧鞋没有独立采用道具母版，本图补全的鞋口、损坏位置与程度均为候选，不自动成为剧情事实。

## 03 临水作坊暮色

![临水作坊暮色](03-临水作坊-暮色借景试验.png)

直接编辑“作坊望半园01”：工作台在近景右侧，水巷隔在两岸之间，对面为家门，桥在左侧。把时段改成暮色，以近处台灯、对岸门灯与水中倒影建立注意力联系。

这张最明显地从展示环境转向可联想到“工作后望向家”的情绪构图。判断属于主观审看，未做观众测试。原木、靛蓝布包与白墙仍可识别，受环境光影响外观改变，不视为采用配色重定。生成后远景窗灯仍偏多，包裹细节和少量构件有重绘；不声称严格建筑/道具一致性。原图的拱桥和门前台阶问题继续存在，本轮不处理空间通路。
