## 这版的衔接决定

- A002用已采用的床侧中近景交代人物与钟，不为全屋开场再补一图。
- A003先轻拳，抱紧翻身并举汤圆到脸前；A004第二拳打汤圆，保留“好烦啊 / 打的是我”。
- A005停在按钟、软臂尚展开；A006才收手、汤圆挪到枕边、知夏坐稳。
- A007沿用坐稳图，只拍床播报与画外启动；A008—010依次完成拖鞋、开柜、送水。
- 全景01的家具已经到位，只作为A014静止状态使用；不是A007的实际首尾帧。
- A012复用窗右书桌薄屏，显示“今日无安排”“早起出门：已开启”；4秒可直接持有静帧，正式字幕/界面可后期替换锁定。
- A015末只躺回伸手，A016才由汤圆主动靠回并相拥。可以把这两镜作为连续素材生成再剪辑，终态图07不提前放到A015结束。
- 参考不是全部可直接作首帧：开门图、伸手图、受拳图、喊停图分别是关键状态或终态；审阅页逐张标明。

## 当前可判断与不可判断

已目视检查本批8张：镜头意图、主要道具、单杯单托盘、双扇柜门、喊停手势、相拥睡向及汤圆眼神可读。整体房间关系延续床左、中央园窗、窗左柜、窗下矮书架和窗右书桌。

合景仍存在图像重绘差异：睡衣胸前锦鲤荷花图案、袖口与领口细节、小耳饰形状、发量、汤圆尺度、钟面指针/刻度、杯托叶缘、柜内衣物及玻璃底座细节。它们没有获得改定款授权。正式视频应把人物一致性修复v1.0睡衣主图、汤圆02、采用闹钟出场图共同作为依据，而不是从各近景提炼不同定款。

静帧不能验证翻身举盾、双手释放按钟、收臂坐起、汤圆自行移动和坐卧转换；动态路径与配音节奏尚未实测。A004受拳触点靠近屏边，实际动作应落在软壳。新图画幅为近似16:9，最终视频适配统一尺寸。
