## 空间设计

- 左侧木床靠实墙，避免窗与门都集中在床头；床右侧空地用于起身、送茶与通行。
- 后窗借景真实池庭，窗下书桌可读书、写东西；右后门通向有遮蔽的园廊，右侧设展示衣柜。
- 书桌边低软垫是汤圆在共享卧室里的停留角，架上有可研究的小器物；不等于已经确定独立小房间的布局。
- 知夏穿现有青瓷绿睡衣，抱汤圆入睡。画面发生在叫醒之前，给随后家具集体启动留下反差。
- 床头收起的软拳套、墙面日出投影、悬浮茶托与嵌入顶面的投影装置提供科技细节，木作、布料与园景承担日常氛围。

提示词暂用约5×4.5米房间、约1.4米床帮助控制尺度；图像不具有精确尺寸，不能作为测量依据。床窗左右关系只是本机位的局部候选，尚未放入半园整体模型，不由图像推断建筑朝向。

## 实图审看

主要家具、庭院视线与中间走道可辨，人物拥抱关系自然；未见需阻断讨论的明显多肢或换装。现有睡衣青瓷绿、奶油白边和头发配饰有所延续，胸前锦鲤荷花被汤圆与姿势遮挡，无法验证完整图案；这张远景也不能代替角色近景一致性验证。

汤圆的奶白圆体、弧形屏、无嘴与金色环带保留，但仍显圆挺，轻微受压的柔软感不充分。后续需要单独验证抱枕模式受压与恢复，不把这张当作变形定稿。软拳套可见但伸缩机构不明确；语音、叫醒、坐起与茶托移动均未验证。门槛细节、真实通行尺寸、日照及与总平面的连接待后续空间建模。
