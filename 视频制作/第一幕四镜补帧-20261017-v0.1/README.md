## E01-A-011

![E01-A-011](E01-A-011-整窗水巷-真实纵深.png)

知夏仍靠高枕坐在床左侧，脸朝窗右书桌，汤圆留在枕边；杯盘在床侧，杯身显示42°C。整扇木窗的中间及窗棂后呈现连贯水巷，岸边植物、水面、建筑与拱桥形成远近层次，没有悬浮矩形或发光边框。衣柜开着，服装在柜口；被面保留局部珠光显像表情。

限制：整窗景象切换、知夏追随声源转眼及三路声音叠加尚未动态制作。本机位没有展示镜面，应继承A009的预设模式。杯盘需锁定与A010同一停点；被角表情转换和对白仍需动态验证。静帧只证明透视与层次构图，不证明移动镜头中的视差或全息显示机理。

## E01-A-014

![E01-A-014](E01-A-014-喊停后全景.png)

卧室全景中，知夏仍坐在高靠枕前，汤圆在旁；床头玉璧及衣柜玉扣保留。柜门敞开，实物服装留在柜口，门内镜面映出房间与窗景、没有虚拟试穿人。中央窗回到原园景，荷叶托盘承杯，杯身无读数，被面不再显脸。床头仍有暖亮线。

限制：本图对应停止晨间播报之后、床准备轻声询问的状态，不能写成全屋完全灭光。镜面退出预览、窗景合回、被角表情淡出、衣架晃稳与停止播报的过程仍待视频；普通镜面精确反射关系未做3D校验。
