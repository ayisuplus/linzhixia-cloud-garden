## 空间构思

从学生园居外廊向外看：左侧是住处，中间是上下相接的水庭与低桥，右侧是带实体练习平台的练功厅，曲廊把各院落接起来。远端在墨雾中留出继续前行的方向。整体天空、山林与外部庭院均处于水墨世界，只有门内少量暖色生活空间。

包裹从左侧宿舍寄出，先撤离檐口和栏杆，再越过水庭开放空域，经过练功厅外侧，向远端墨雾离开。路线拓扑、步行关系与C段镜头组织见[空间布局与首集航线](../../世界观/山水书院-空间布局与首集航线-v0.1.md)。

## 实际审看

- 近景柱、檐与栏杆，中景水庭、桥、曲廊和右侧练功厅构成清楚的遮挡与景深关系；比宿舍02仅在外侧露出远山更能表达可穿行的校园。
- 水面与右侧叠水能够对应，低桥和岸边路径可辨。三层设计意图没有完整表现为可核对的标高体系，连续缓坡也未完整显现，不能替代三维通路验证。
- 外部天空、山、树与水庭为黑白灰；左侧门内保留暖色，局部灯具也有少量暖光。图像不是全画幅严格零彩度。
- 山峰仍比提示要求密集，远景有装饰性；建筑仍偏传统园林，右侧大厅用途可供练舞，但图像本身缺少足够教学活动线索。未来课堂的切换能力未在本图展示。
- 新图左侧寄件台与栏杆的关系尚不适合直接拍起飞；需在载具与栖架设计中调整开口、落点和净空。图中包裹是占位，不锁定包装母版。
- 使用宿舍02作建筑语言参考，不等于完成了两个机位的精确三维对齐；总景里宿舍门、廊与近景构件有重新生成。
- 无人物、神鸟造型或视频。独立学院与云城的边界机制仍待设计。
