## 表演与连续性

忙乱来自几件家具过度热心地同时服务。椅子退出、日历朝向知夏、被缘抬起、衣物轻摆等是动态制作计划；图片只提供对应姿态。主动语音仍控制在窗、衣柜、水杯最多三路。杯盘沿用A010停点，不重复飞入；拖鞋在A008对齐后因知夏没有伸脚而再次微调，解释A011的错位。

喊停时保留物件在半途的位置，不瞬间收拾房间。A014是立即停下的关键动作状态：被缘表情尚在，不标为完全淡出的结束帧。随后表情淡去、床轻声询问，A015收到点头再降低枕头，协助她躺回。

知夏在A011双手攥近身被缘；显像抬起处在腿边，与双手分开。高枕仍在背后，她前倾离开承托。两张全景未展示衣柜镜面，不能把镜外的空白当成预览提前退出，也不能声称已验证普通镜面反射。

被缘仍连接整条被子，显像带织纹，比A007/A010光滑隆起的候选更像被面。二者的材质变化尚需动态连接，不能把两种静态形态当成完成的变形演示。A013仍是旧姿态参考，其高枕、玉璧及新增忙碌姿态的限制保留在图册中。
