# 云海中的园城 · 空间候选

作者反馈：建筑已可以，但城市像几块飘在天上的板子。此轮保留上版近景建筑与58秒航线，重做周围云海关系。

## 打开

- [实际渲染对照](review.html)：7处原航线机位与额外全景。
- `cloudsea-city-v04.blend`：本轮可编辑候选，原58秒时间线仍在。使用Cycles显示本轮云体受光；不能直接沿用旧EEVEE快速预览作为等效画面。
- `preview-v04/`：本轮最终静帧。未重录58秒MP4。
- 在文件夹中双击 `打开云海工程.cmd` 可直接启动本机Blender并加载本轮工程。

## 改动

城市下方建立连续、起伏的低云海；岛间云流连接各区，岸云只在局部上卷，打断完整托盘轮廓。远景以现有建筑语汇增加35组院落实例，省去独立硬地底面，让屋顶、墙体和树冠从云中露出；它们是背景候选，不替代原城市布局或游戏可行走资产。

学校与园城现有建筑配色、近景布局和飞行路线沿用。原始v04工程保留。新增云为光学体积，几何无碰撞不等于视线无遮挡，需看实际画面。

## 试验与检查

最初EEVEE高补光把云海压成白地板；降低补光后又成为灰雾。切换Cycles检查真实体积受光后可见云团起伏，但上卷过高的一版遮住了城区，已降低海中云脊并减少上卷岸云。失败版本与图片保留在本目录，未标为采用。

最终对照左图来自旧EEVEE视频，右图为新Cycles静帧；机位相同但照明呈现有引擎差异。这不是仅隔离云体一个变量的材质实验。独立保护审查与视觉观察见 `review/`；文件哈希见 `delivery-manifest.json`。作者采用与完整动态观看仍待审。

[独立数据保护审计](independent-preservation-audit.json)确认原51774对象、51706几何块、8动作数据无意外修改，556个旧云对象更换云材质绑定；原建筑仍使用的材质参数不变。主代理已逐张查看7个原航线机位与额外全景，详情见[视觉记录](review/visual-review.md)。局部庭院前缘、桥头和部分岸线仍有硬边，本轮不标为最终定稿。

## 复现

显式项目根目录：`E:/projects/内容创作/未来女孩林知夏`。

本轮脚本位于 `第一季/制作/空间规划/第一集云海城市-v0.1/`：

1. Blender后台运行 `build_cloudsea.py -- --root <项目目录>`，从原航线v04生成云海v02。
2. Blender后台运行 `render_cloudsea.py -- --root <项目目录>`，生成上卷较高的v03试验。
3. Blender后台运行 `refine_visibility.py -- --root <项目目录>`，生成最终v04和8张静帧。
4. Python运行 `package_review.py --root <项目目录>`，制作对照与审阅页。

只做Blender空间参考，未提交任何视频生成模型。
