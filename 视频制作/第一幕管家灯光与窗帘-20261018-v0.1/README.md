## 叙事与光线

闭帘暗室熟睡→闹钟响、床灯低亮→三次催醒→坐起被检测到→原枕托背→分区灯依次亮、厚帘先开纱帘后开→原庭院（厚帘开启时通廊卷帘同步升起）→家具服务→贴窗追波纹换成水巷→日历揭示周末但闹钟仍开启→喊停，只停催促→她说忘关闹钟，床等待决定→点头再睡才取消本次唤醒→回庭院、纱帘先合厚帘后合、通廊卷帘下降、分区灯退下→抱回汤圆→床灯最后熄灭。

全屋管家是无形协调层，没有新头像和新的播报角色。坐起触发预设流程不等于她同意起床；喊停后等待她回应。只取消本次唤醒与重响，不自动修改未来所有闹钟。后台安防继续运行，不另加安防展示镜头。

主窗保留木质外框、原窗台和窗下墙，中央玻璃连续、无内部横竖格。新增至窗台下缘的双层短帘，双轨藏在外框上方，开帘后两侧收纳，避开衣柜旋臂与贴窗相机路径。右侧通廊入口另设隐藏遮光卷帘，原木格门不改；睡眠时降至地面，防止侧面日光漏入，室外仍是同一清晨。开场与终场已补卷帘关闭修订，未补前两张保留为历史。窗帘外观仍是候选，轨道、堆叠与避让未作工程验证。

新增E01-A-000（4秒）、E01-A-007-L（6秒）、E01-A-016-L（4秒），A014由6秒到8秒；保留原18个稳定ID及其余时长。合计21镜115秒预算，比99秒增加16秒。8批AI规划加日历插镜：126秒原片＋4秒插镜－15秒剪辑余量＝115秒。模型参数沿用历史规划，未现场验证可选时长，未提交生成。

16张当前图像、可见事实、用途与逐张限制见[manifest.json](manifest.json)；参考、生成工具与原始输出见[generation-inputs.json](generation-inputs.json)。原始Prompt放prompts，不写在图像中。文件通过copy-inputs.json复制，生成目录原件保留。

- A007-L是灯帘状态候选，高枕承托与被面表情尚须跟A007统一；逐盏亮灯不是静帧已验证动作。
- A011/A014/终场继承旧全景小挂钩，应以A009刚性直连衣架为机构依据。帘缝疑似竖线不作为窗格依据，主玻璃仍连续。镜头未重绘部分也须按新帘状态约束。
- 暗室允许微弱轮廓，不为纯黑牺牲动作可读性；床头玉璧提示光不等同房间照明，实体不消失。停下的衣柜、杯盘和椅子不瞬间恢复开场。
- 开灯、帘轨运动、织物转换、承托、口型、音效和贴窗飞行仍待动态验证；图像候选不等于作者逐张采用。
