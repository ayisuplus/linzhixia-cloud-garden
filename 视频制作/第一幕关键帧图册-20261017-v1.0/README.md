本轮精修图册结构与交接，不改图片、配色或动作剧情。七份母版/状态参考、16镜总览及单镜制作卡；四处完整画面缺口保持。每镜补足用途、动作起止、必须保持与相邻镜衔接；显式标注已有图是起始、关键动作、结束还是界面参考。

图册可筛选缺口、建议动态试验镜头，可搜索编号/名称并打印。母版只在注明的范围内约束画面。没有生成媒体，也不因整理将候选提升为作者采用。
