旧05、校服v2.0和睡衣08文件保留为历史，人物画布当前节点已指向去纹版。更早未采用的校服试稿不再作为当前设计依据，未逐一重绘。ToonFlow全局素材库不在本次同步范围，不能继续把其中旧云纹版当最新。没有导入Eagle。

## 后续设计约束

所有造型不再增加腿部皮肤云纹，不再将其描述为固定或不可拆身体标记。便服图按作者要求保持原样；袜口及鞋服的装饰纹样不受本次取消身体标记影响。睡衣采用08款式配色，最新去纹图为[睡衣09](../知夏睡衣精修-20261012-v0.1/睡衣09-记录.md)。校服面容未在本轮重塑，后续身份主参考仍为便服07。侧背补全和非精确正交限制沿用v2.0。
