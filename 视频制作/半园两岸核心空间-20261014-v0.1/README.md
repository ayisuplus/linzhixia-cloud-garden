## 设计

- 作坊临水，门前留门廊和连续公共步道；桥偏在入口一侧，家门到作坊有短转折，既有景深也保持日常联系。
- 接待靠近入口，修复台能朝向水巷与家门；材料收纳放后侧。干燥试用区独立留空，避免与工具台及临水区域混用。
- 收件位置暂放作坊侧面，不占正门；无人机仍负责首集送包裹，但接近、停靠和交接方式尚未验证。
- 家中原工坊区域暂腾作种植与休息庭院，家庭茶廊服务生活；客人主要在对岸作坊接待。

![平面候选](两岸空间关系-平面候选.png)

平面使用局部米制坐标：家园沿用28×24米讨论院界，水巷约5米，两岸步道各约3米；作坊暂按14.5×8米，门廊另计，试用空地4.5×3.5米。所有数字均为工作假设，不代表概念图达到了精确尺寸。橙线为通路，蓝虚线为构图方向，未进行人形碰撞或无障碍验证。

## 图像检查

实际查看生成图，前景工作台、中景水巷、左侧桥和对岸家门关系清楚；门内只露出局部庭树与路径，没有穿透实体院墙展示全院。室内有可读细节，水面反光和远景云城延续上一稿气氛。
