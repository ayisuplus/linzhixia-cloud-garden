## 当前设计

面容以作者选定的[便服07](../知夏便服精修-20261012-v0.1/知夏-便服07-花绣与玉坠.png)为准。衣着依据[便服15](../知夏便服精修-20261012-v0.1/知夏-便服15-后脑发结玉簪与双白袜.png)，保留珊瑚短衫、水青花鸟裙、哑光织纹及11版小皮鞋方向。后脑结构参照本版妆造板：两侧编发汇入后脑小编结，玉簪横穿真实发束，簪身大部分藏于发结内；簪首在人物左侧，正面自然遮挡。

以下左右均为人物自身左右：右腿暖白不透膝下长袜，平窄袜口、白线竖回纹，遮住固定右小腿云纹；左腿同色短袜，如意弧口、稀疏白线云纹。去掉智能发夹、腕环和腰间终端；保留右侧花饰，换左腕闭合玉镯、右腰玉坠与短流苏。

侧背及遮挡结构为合理补全，非精确正交建模图或服装纸样。朝左侧面远侧长袜腿大部分被近侧短袜腿遮挡；正面有轻微自然歪头。成图不代表作者已逐项接受补全细节。
