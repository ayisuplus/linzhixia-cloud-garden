## 查找与恢复

按 manifest.json 中的节点名称、ID、文件路径查找旧稿；清理前的完整画布记录为“人物设计-清理前.snapshot.txt”。
如需将某张历史图重新用于制作，应通过 ToonFlow MCP 添加图片/文本节点并引用归档文件，不能直接覆写当前画布 JSON。
校服正面独立图为大半身；侧背及遮挡结构仍属于生成补全。其他三套服装是认可初稿，两张场景是方向参考。
图片不纳入 Git，搬迁时需一起复制整个“视频制作”目录；Git 提交不等于媒体备份。
