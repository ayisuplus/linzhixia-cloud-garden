## 已落到工程的内容

- 一条连续云质地形与主水脉，穿过学园山坳、夹谷溪路、水湾邻里和半园/作坊生活水巷。主水脉约1.82公里，属于第一集沿线的布局骨架，未铺满整个城市远区。
- 上游庭水96米、中部水湾38米、下游水巷18米；主要落差集中在连接窄溪。高程和距离均是本白模设计值，非实测资料。隐藏回水管只表达循环关系，没有流体仿真。
- 50处不同占地的院落白模，院内端正，邻近小组共用朝向，再随岸线转折。近水台地与坡上街道分别落位；共用水岸平台、休息亭与植物预留带已占位。
- 两岸岸路、两条坡街、4处跨水桥（含上游框门桥）、入院通路和5处坡路连接。坡街按自身路程组织缓慢下降，随后安排坡上院落高程。
- 一处“坡街—中层门洞—院内连廊—升降井预留”的连接。中层开口实际贯通，转角平台补齐。升降井只预留空间，不是可运行的电梯；安全栏杆与正式无障碍方案未做。
- 上方和侧方的云体独立分层。总图工程默认关闭渲染云，便于检查地形；粗试飞开启。它们是本轮空间气氛占位，尚非最终云海材质。

## 新航线

旧逐帧航线已退出约束。新路线约1.745公里，58秒、24fps、1392原生帧，960×540。穿过上游圆框，顺谷转入水湾；后段降到贴水高度、经过桥下，再转向作坊入口。镜头先随转弯方向，再渐变到目的地朝向。

当前计算最大速度约37.62米/秒，相邻帧最大转角约0.907度，最大离散加速度约25.69米/秒²。这里只验证动画空间和节奏，未模拟真实飞行动力学，不作为无人机可执行航线。

使用1.1×1.1×0.7米的参考载体包围范围，27个偏移点逐段扫掠未检出实体相交；这不是精确连续实体碰撞证明。参数与逐帧姿态分别保存在 `route-check.json`、`route-poses.json`。生成参考可用0—30秒和28—58秒两批，保留2秒重叠；未提交任何云端生成。

## 检查与现有限制

独立检查保留了失败初版及每次修订证据。修正过院坪互相影响、水湾倾斜、过陡路段、二层缺板和坡路悬空等问题；最终结论以[局部复核](independent-review-final-06.md)及[前一轮整体核验](independent-review-final-04.md)为准。整体核验中院坪投影冲突、跨院建筑交叠、路面上方的建筑/屋顶命中为0；最大路面纵坡约27.76%，仍有较陡生活坡路，未按完整无障碍城市验收。

视频交付后由 `video-validation.json` 记录全部PNG检查与三条视频完整解码结果。全程117个抽样画面用于检查明显穿帮和构图；抽帧不等于连续播放舒适度验收。作者对布局、园林气质和速度的采用意见待确认。

**白模仍有局限：**建筑形式重复，街区生活内容与植物资产尚未展开；水岸和切坡有网格棱角，远区尚薄；云偏概括，近景细节与材质精度低。本轮延续原黛青、暖墙、青碧水和木色参考，不把浅色地形当作新的最终配色。

## 打开与复现

聊天中的 `.blend` 链接可能触发下载而不是自动启动 Blender。使用 Blender 的“文件 → 打开”，选择本目录的 `landscape-masterplan-v08.blend`；需要看相机动作则打开 `landscape-route-58s-v08.blend`。工程使用 Blender 5.1。

脚本位于 `第一季/制作/空间规划/第一集山水总图白模-v0.1`。按 `build.py → finalize_geometry.py → flight.py → render_views.py → render_flight.py full → package.py` 顺序执行。Blender脚本参数均为 `-- <项目根目录>`，render_flight另接`full`；section.py和package.py用本机Python运行并接项目根目录。布局数据只由layout.py生成，不另增人工维护表。

源文件、完整动作、剖面、核验数据与本轮脚本保留；PNG帧序列作为本地可重建渲染缓存，不纳入Git。未更改原采用图册、人物、服装、剧情或旧工程。
