本轮在v06云内园城上添加一组云包石山、山肩蓄水、岩壁短瀑和穿山栈道，作为第一集58秒飞行的空间参考。原版保留，候选等待作者审阅。

## 设计与复核

新增159个对象、3个材质。主峰与山脚云集中在原叠水庭东侧，山肩池通过短瀑与接水槽进入既有水庭；圆角栈道由池岸进入洞口。原有52,024个对象、原材质/绑定、灯光、世界、显示、合成和动作保持。

中段低脊和散石曾侵入原书屋、步道，已从最终版撤回；横段栈道北移并圆角处理，瀑布岩槽清空，前侧云遮住完整浮石底腹。失败候选保留在`trial-a-preview`，中期审查记录不代表最终版。

- [设计说明](../../第一季/制作/空间规划/第一集云山水城-v0.1/设计说明.md)
- `independent-audit.json`：可编辑v06/v07资产保护审计通过，1392帧相机位置/四元数和载体位置最大差为0。
- `independent-geometry-final.json`：新增实体对路线的连续线段包围盒净距下界，载体约48.37米、相机约49.18米；未触发近邻稠密射线。石山与检查范围内原物体无相交，529个栈道中心线采样未见人体阻挡或内部地板缺口。未认证完整旧地面接入、实例展开、导航或工程规范。
- `proxy-image-comparison.json`：源工程与快速渲染副本300/600帧的平均通道差约0.067/0.047（255级），不称完全逐像素相同。

- `final-review.md`：最终抽帧审看与限制。

## 精度与保留

这是空间/机位参考，石峰仍偏圆润，体积云有颗粒与细条纹，瀑布是静态水帘几何，不是流体模拟。原池岸与树形仍是预演精度；植物体系未在本轮扩建。资产保护、解码和抽帧通过不等于连续观看舒适度或最终美术采用。

本地保留源工程、渲染派生工程、诊断、副本、图片与视频。Git保存完整源工程、构建/渲染脚本、审计及说明；派生大文件和生成媒体沿项目规则忽略。`render-only-batched-v07.blend`只服务快速渲染，不能替代可编辑源。

重建依次执行空间规划目录的`make_rocks.py`、`build_landscape.py --root 项目路径`。代理构建加`--proxy`；`render.py --root 项目路径 --file render-only-batched-v07.blend --full --output frames`渲染完整序列；`package.py --root 项目路径`打包。局部重建必须重新核对源/代理与审计哈希。
