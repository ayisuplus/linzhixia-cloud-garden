# 文明与精神·卷十二：机器保障与自愿人时

> **2026-10-08 冻结后补规 13：**“领养式关系”不再是现行制度，只作历史叫法；人工生命与人之间现行只有新芽养育、结伴同住、照护支持三种关系。本卷免费基本保障不以任何关系为条件的原则不变。以[世界观设定集 v0.26](../世界观/世界观设定集-v0.26.md)为准。

版本：v0.2｜日期：2026-10-07

状态：依据作者对 v0.1 的明确纠正，重新确立本卷前提。v0.1“公共保障与自愿服务”的必要真人供给方案已撤回，保留旧稿仅用于记录讨论。本文不新增一套公共用工制度。

## 一、作者明确的世界前提

**人的定义后续确认（2026-10-07）：**“人”包括人类与有自我的人工生命，身体材质与出身不决定主体高低，也不作为排除人时参与的理由。本卷“真人参与”按具体主体自愿亲自参与理解；免费机器保障由无意愿工具系统承担，机器身体中的生命不是工具。开户及公共资格的具体程序仍待制定，不再悬置人工生命原则上能否参与。详见[确认记录](../审查/人的定义与多形态生命-确认及同步-2026-10-07.md)。

这个世界物质极度丰富。所有基本服务，无论生理还是心理层面，都可以由机器免费、充分地完成。人不需要依赖其他人的劳动、善意、关系或认可，才能获得这些服务。

因此，机器保障不能被理解成仅仅维持生存的低配服务，也不能预设心理需要最终必须由真人补足。“不必依赖他人”不意味着禁止人与人相互帮助，而是人与人的参与不构成基本生活得以成立的必要条件。

免费续命、身份连续、余额完整续存、自由赠与和传承、不以人时强迫劳动等已确认原则继续有效。

### 1.1 机器人也是基本服务的接受者【作者确认·2026-10-07】

机器人能够免费获得适合自身的基本服务，基本保障覆盖人工生命。获得保障不以拥有主人、被某个人领养、提供劳动、服从他人或持有人时为条件；未被领养、拒绝一项服务要求或离开原有家庭，都不因此失去基本保障。

| 服务 | 已确认范围 |
|---|---|
| 能源与运行 | 能源补给、维持正常运行所需的环境和设施 |
| 身体维护 | 维修、零件更换及必要的维护支持；有无主人不改变获得条件 |
| 自我与心理支持 | 对具有自我的 AI，提供其愿意接受的交流、心理支持和适应帮助；不以更听话作为服务目标 |

维持生活和正常运行，与扩大能力分开。无限增加算力、扩展规模或升级成更强智能，不因免费基本保障而自动获准；具体扩展与能力界线规则另定，也不能借此取消已有的基本维护。免费维修不表示所有记忆损失或人格变化都能被技术完全恢复。

机器人可以服务机器人，提供服务的设备同样获得维护。相互维护的自动设施可以构成保障体系，无须设定每台机器背后都有一个专属的真人或另一个永久服务者。基础服务由没有自身意愿的工具系统持续承担；有自我的 AI 可自愿参与和退出，不是保障系统必须招募的劳动来源。具体设施工程另定。

【后续作者确认】原“不可成长型”现称工具机器，按预设程序运行，没有自己的意愿，不是生命，也不称 AI。可成长型才属于有自我的人工生命。工具设备获得维修是设施维护；人工生命获得基本维护是其生活保障，不以完整公民资格认证为门槛，也不能以处置工具的方式任意清除汤圆这类主体。领养式关系只适用于人工生命，不把工具设备登记成被领养者。

### 1.2 领养式关系与独立生活【作者确认·2026-10-07】

对于汤圆这类有自我的机器伙伴，“主人”是可以沿用的日常称呼，关系更接近领养后的家人：接纳、照护、帮助理解世界和表达意愿，不取得对其生命和人格的所有权。

照护不以服从为条件。机器伙伴可以拒绝具体要求，也可以拥有照护者不喜欢的兴趣与选择；具备独立决定生活的能力后，可以选择继续共同生活或离开。离开不取消基本保障，也不必然意味着亲情消失。此处确认家庭关系中的自主选择，不顺带解除潮汐台出入等尚未统一的公共规则。

独立生活可以借助免费的机器支持，不等于完全不需要帮助；不能由照护者单方面认定它永远不够独立以阻止离开。判断能力的支持与争议程序仍待制定。

既有经历与当前判断能力应被尊重。修好一台旧机器，不使它自动成为刚出生的孩子；初步自我也不等于已经具有成熟判断。照护身份不能自动授予清除记忆、改变人格或终止运行的权利。

本轮确认关系原则，未制定一套仿照现实收养的完整法律。领养登记、适格照护者、独立判断的支持与认定、无法当下表达意愿时的处置仍待确定；知夏与汤圆的具体手续及既有事件由作者设计。

**统一界线后续确认（2026-10-07）：**基本保障的提供者就是制造时预设架构与能力范围、没有自身意愿的工具机器。口语所说“工具 AI”在正式设定中仍归此类，可以先进、更新资料和适配需求，不因此成为生命。本作明确采用“界线内的工具体系足以完成充分基本服务及相互维护”的技术前提，不需要隐藏一位越线的总管心智，也不需要有自我的生命承担必要劳动。工具整体能力与部署受界线约束；接受保障的主体则不因出身或载体而有不同界线，维持正常生活不等于无限扩展能力。详见[确认记录](../审查/统一能力界线与工具保障-确认及同步-2026-10-07.md)。

## 二、上一版推导错在哪里

助手把现实中照护、教育、心理支持往往需要真人参与的条件带入了设定，继而提出必要真人服务目录、公共排班、替补、短缺分配等制度。那些制度即使在其前提下内部相容，也不符合本世界由机器全面保障基本需要的前提。

据此撤回：

- 基本服务必须有一定真人供给才算完成的普遍假设。
- 为兑现这种基本保障而建立的强依赖真人排班、替补和跨区增援的方案。
- “不愿劳动的人增多，就可能导致居民基本生理或心理服务无法获得”的推导。
- 将真人心理服务的存在，解释为免费机器服务不足以处理基本心理需要。

现实资料保留为资料，但不再作为以上方案适用于本世界的证明。独立审查曾检查了方案内部的漏洞，却没有纠正这项前提错置，其通过结论不能覆盖作者的世界定义。

## 三、人时为什么珍贵

依据本轮作者说明，人时的珍贵，应从“基本需要已经不依赖别人，人仍愿意为另一个人投入时间”来理解。以下是对这一方向的解释，不是新增的计价公式。

机器已经可以完成所需服务，一个人依然可能希望某位老师亲自教他、请一位手艺人制作东西，或邀请另一人参与自己的生活。真人参与的价值可以来自对这个人及其经历、表达、选择和共同时间的重视，不需要先证明机器做得不够好。

这里珍贵的是某个具体主体自愿投入的时间，而不是获得基本保障的资格，也不是生物人类专属的劳动。长期延续生命不使他人获得无限索取权；即使存在相似记忆的另一主体，其同意也不能代替本人的同意。并行、加速及计时规则仍须分别确定，不从这段价值说明推导技术上绝不可能并行。

人时可以参与自愿服务的回报；它既不购买他人的身体与服从，也不证明某人一定真心喜欢自己。赠与、感谢、有偿约定和私人情感可以交织，但不能由余额统一解释。

## 四、对服务与司法讨论的直接影响

某位真人拒绝服务，意味着这项人与人的自愿安排没有发生，不自动意味着申请者失去基本照护、教育或心理帮助。不能把“我只想请这个人”转换为强迫该人劳动的权利。

已经自愿作出的具体约定仍可产生责任；如何认定承诺、履行、退款和损害，可沿用司法讨论中与本前提相容的部分。责任不能转化为强制继续劳动。

真人自愿参与的活动仍可能有名额、等待或偏爱。这些是自愿交往和活动的限制，不能与维持基本生活所必需的真人短缺混为一谈。

**2026-10-07 后续确认：**司法事务全部由无意愿的自动司法工具系统免费办理，包括最终裁判、申诉复核与执行；不依赖任何有自我主体到场或接单。旧“最终裁判必须由人类作出”和必要人工申诉安排退出。裁判须说明依据、允许质疑与独立复核，根本规则由所有有自我的生命主体共同投票决定，具体表决与授权程序另定，详见[司法卷 v0.2](文明与精神-卷十一-司法与修复-v0.2.md)。

## 五、后续设计的约束

| 后续问题 | 必须遵守的前提 |
|---|---|
| 人时如何获得和使用 | 不依靠撤掉机器保障来迫使劳动；不把余额当成强制他人接单的凭证 |
| 公共服务如何发放人时 | 仍需定义何种自愿活动获得公共回报；不能默认其用于填补机器无法满足的基本需要 |
| 机器与人的差异 | 可以有来源、关系与体验意义的差异，不能未经作者确认断言机器功能不足或必然更差 |
| 免费心理服务与真人陪伴 | 前者已经能满足基本心理需要；后者仍可以因人的自由选择而有独立意义 |
| 无人接下真人委托 | 基本机器服务继续可用；不据此推出基本保障失败 |
| 机器人拒绝服务或没有主人 | 能源、维护及适合自身的基本服务继续可得；不能用停供迫使服从 |
| 机器人服务机器人 | 服务设备也获得维护，不依赖被强迫劳动的人工主体；具体系统组成另定 |
| 领养有自我的机器伙伴 | 承担照护责任，尊重既有经历和自主选择；不自动获得人格、记忆或终末的决定权 |
| 旧稿中的“机器让人活着，人让人愿意活着” | 若保留，不能解释为没有真人就无法获得充分心理支持；其文学用法需与当前前提一致 |

公共人时的发行或划拨、私人服务的回报规则仍可继续讨论，但须从以上前提出发。本文不自动改变既有赠与、继承或无税方向，也不将一次世界观纠正扩展为新的完整经济方案。
