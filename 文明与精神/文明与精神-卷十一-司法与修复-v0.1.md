## 一、这个世界为什么仍然需要司法

物质充足，消除了许多因匮乏发生的冲突，但不会消除失约、欺骗、伤害、误解和偏爱。真人的时间有限，人的感受不能由机器统一计算。记录再准确，也不能自动回答一个人是否同意、是否受到了压力、是否应当承担责任。

司法承担三件事：确认需要负责的行为，保护受到侵害的人，使责任以有限而可执行的方式落实。修复关系是一种可能的结果，不能成为受害者必须完成的任务。

作者已经确定的边界继续有效：续命免费；蜕皮前后是同一个人；余额完整续存，可以赠与和传承；不征收服务税或蜕皮税。任何司法措施都不能以撤掉生存保障或续命资格逼人劳动。

本卷选择以下制度方向。这些是本轮受托设计的内容，不倒写成作者此前已经确认的决定：

| 问题 | 本卷采用的规则 |
|---|---|
| 服务是否必须收费 | 不必须；无偿帮助、事后赠谢和约定报酬都合法 |
| 明确承诺是否有约束力 | 有；有效的报酬约定可以请求裁判和执行 |
| 私人报酬从哪里来 | 接受服务、承担约定的人转出已有余额；判决本身不创造人时 |
| 一小时是否自动产生一人时欠款 | 不会；时长是履行证据和必要时的估算参照 |
| 公共司法服务怎样计酬 | 按公开公共服务规则，由智能系统发放；不向当事人按输赢收费 |
| 谁作最终判断 | 人类裁判者负责；AI 提供可质疑的辅助材料 |
| 如何执行 | 设置有法定权限、专业训练和独立监督的保护及执行人员 |

如果连明确报酬承诺都允许随时反悔，单纯未付款就不能作为欠款追缴。本卷没有采用这一支，因为它会使大多数私人报酬争议只能停留在人情和信誉层面，难以支撑作者希望展开的司法故事。

## 二、私人服务：付出、感谢和债务是三回事

### 1. 三种日常关系

**无偿帮助。** “我替你修，不用给。”之后即使没有收到感谢，也不能把这段时间追溯改成收费服务。无偿不等于可以随意损坏他人的东西；是否存在其他侵害另行判断。

**事后赠谢。** 事先没有报酬约定，接受帮助的人可以不给、少给或多给。人与人的偏爱可以留在这里，系统不替双方计算应有的感激。

**有偿委托。** “请帮我修复这张照片，完成后给你两个人时。”双方自由同意，且约定不违反基本权利，便产生相应义务。付款可以依法执行，但双方仍可以协商免除、减少或延期。

口头约定、消息和足以证明双方意思的行为都可以作为证据，不要求每一次帮忙都先填写标准合同。沉默、接受礼物或过去曾经赠谢，单独都不足以证明同意这次付费。对方没有请求、也没有接受收费条件的服务，不能只靠计时开账单。

这种区分参考了自由订约、有效约定具有约束力、约定不必一律书面化的制度思路；引用的 UNIDROIT 文本适用于国际商事合同，本卷仅借用概念，不把它直接当成这个世界的人际交往法律。[资料：UNIDROIT Principles 2016，第 1.1—1.3、2.1.6 条](https://www.unidroit.org/wp-content/uploads/2021/06/Unidroit-Principles-2016-English-bl.pdf)

### 2. 怎样判断欠了多少

裁判依次判断：有没有接受这项服务，双方是否理解为有偿，约定了什么范围和质量，约定了多少报酬，实际完成了什么。证明服务发生，不能替代后面几步。

- 有明确总额的，先按总额和履行情况判断。
- 按时计酬的，核实约定范围内的合理工作时间；不能把闲置计时或未经同意的追加项目塞入账单。
- 确认双方都理解为有偿，但没有谈妥数额的，可参考委托时已公开、双方能够合理知悉的人时基准，并结合合理工时裁定。没有可知基准，就不能临时以某个行会标准强加给接受方；法院须说明估算依据，当事人可以争辩。
- 连是否有偿都无法证明的，不因存在服务时长就判给报酬。另有欺骗或损害证据的，另行处理。

“一小时对应一人时”在本卷中是普通服务的参考尺度，不是所有人际帮助的强制最低价。不同技能的系数是否保留，另由服务制度统一规定；司法不能私自创造一套市场价格。

学徒花了二十小时练习，并不意味着接受服务的人自动欠二十人时。委托目标、事前告知的经验水平、合理工时和追加同意都要考虑。服务承诺是“尽力尝试”还是“达到指定结果”，也应分别理解；没有修好不必然等于欺骗。

### 3. 公共服务另走公开规则

公共司法岗位的资格、计酬和申诉规则由公共程序制定，AI 按规则记录与发放。领取报酬不能与立案数量、胜诉率、罚没金额或促成和解的数量挂钩。

私人客户拒付，不会让这次私人服务自动变成公共服务。法院也不能命令系统为了填平一笔私人欠款而新增人时。

公共发放究竟是新增人时，还是从公共账户划拨，仍属于尚未闭合的整体人时制度。本卷确定职责和禁止事项，不虚构一项税源，也不声称公共账务已经解决。

## 三、一件日常纠纷怎样进入司法

### 1. 先有一个容易走进去的地方

社区设“公议所”，提供免费的权利说明、材料整理、翻译、无障碍协助和法律援助。人时余额少、口齿不清、不会使用 AI，都不能成为失去救济的理由。代理和援助人员承担独立职责，不由对方或行会替当事人选择。

当事人可以直接申请裁判，也可以先尝试调解。涉及人身威胁、持续骚扰或证据即将灭失的，先处理保护请求，不必等待双方坐下来谈心。

### 2. 调解自愿，裁判有约束力

调解员帮助双方表达诉求，不决定谁胜谁败。任何一方可以拒绝或退出；拒绝和解、拒绝道歉，不得作为败诉或有罪的证据。调解中的让步原则上不能被当成庭审中的认责；对现实危险的通报义务，须在会谈前告知。

达成协议后，由独立人员确认知情、自愿、内容合法；双方选择赋予其执行效力时，再由法院确认。受到胁迫或重大误导的协议可以依法撤销，不能因签过字便拒绝调查。

调解不成，案件进入正式裁判。小额服务纠纷可以由一名合格裁判员审理；复杂、涉及重大权利或严重侵害的案件由合议庭审理。双方都能陈述、质证和获得说明理由的决定。缺席不会自动认定对方说的都是真的，仍须核实通知和证据。

“协商未成后进入裁判”参考新加坡小额索偿程序的分工，但不照搬其地域管辖、金额门槛或代理限制。[资料：咨询程序](https://www.judiciary.gov.sg/civil/at-small-claims-consultation)、[审理程序](https://www.judiciary.gov.sg/civil/at-small-claims-hearing)

### 3. 一次独立复核，以及必要的例外

当事人可在收到充分说明理由的决定后申请跨社区复核；语言、健康和送达障碍不能被利用来剥夺这一机会。复核可以审查事实、规则适用和程序错误，由没有参与原案的人负责。

普通案件经复核后终结。出现足以改变结论的新证据、裁判腐败或重大程序侵害，可以依严格条件申请再审；仅因不满意，不能在无限寿命中反复启动同一案件。再审救济也不得绕开禁止重复刑事追诉的保障。

具体申请期限应在正式程序规则中公布，本卷不以一组未经整体协调的天数替代整部程序法。下文涉及人身自由的紧急时限则作为硬性底线明确规定。

## 四、谁可以裁判，AI 可以做到哪一步

### 1. 人类裁判的独立性

裁判者需要经过公开资格审查、法律与证据训练，并说明利益关系。案件随机分配；与当事人有亲属、师徒、密切人情或直接利害关系的，应当回避。地方关系网无法避开时，将案件移交其他地区。

轮任和公共监督可以约束司法职位，但社区不能因为不喜欢正在审理的案件，临时罢免裁判者或投票决定输赢。涉及失职的投诉由独立纪律程序处理；必要的停职与案件接替也必须说明理由，不由诉讼一方控制。

### 2. AI 是证据助手，不是最终裁判

AI 可以整理时间线、核对授权范围、查找规则、提示遗漏和执行已经生效的指令。它不能自行决定证人的可信程度、有罪与否、应承担的责任或是否限制人身自由。

每个可能影响决定的 AI 摘要，都必须能追溯到实际材料，并说明缺失与不确定性。当事人有权查看对自己不利的实质证据，指出错引、漏录、误识别和语境问题。没有机器记录，也可以通过证人、通信和其他证据主张权利。

不可篡改的时间戳，只能增强某份记录在某时存在的可信度，不能证明记录者没有撒谎，更不能证明当事人自由同意。

借鉴的 CEPEJ 宪章强调基本权利、不歧视、质量与安全、透明及审计、使用者控制；“最终责任由人承担”是本世界结合工具型 AI 边界作出的更具体选择，不冒充宪章逐字规定。[资料：CEPEJ 司法 AI 伦理宪章](https://www.coe.int/en/web/cepej/cepej-european-ethical-charter-on-the-use-of-artificial-intelligence-ai-in-judicial-systems-and-their-environment)

### 3. 公开规则，不公开一个人的全部生活

裁判依据、程序规则和经处理的典型判例可以公开。涉及亲密关系、医疗、未成年人和机器主体内部记忆的材料，限制在办案必要范围；公开审理也应有保护这些利益的例外。

任何服务者都不必为了保有权利而全天录音。调取私人记录需要合法理由、限定范围和可审查的授权。为保护第三人而隐去信息时，不得把无法有效质证的隐秘材料作为不利裁判的决定性依据。

法院不发行全民道德分，不制作永久可搜索的“欠账者名单”。保存可追溯的司法档案，与把往事持续展示给所有邻居，是两件不同的事。

## 五、判决以后：承担责任，不出售余生

### 1. 可以要求做什么

普通服务案件主要通过支付已经约定的报酬、返还不当取得的人时、赔偿证明了的损害解决；也可以裁定停止侵害、归还被占有的物品、纠正错误记录。

修复实物或重新提供服务，可以成为双方同意的履行方式。法院不能强迫一个人用未来劳动抵债，也不能强迫受害者继续接受伤害者提供的照护。人格表达性的道歉与宽恕保持自愿；客观错误记录的更正不等于强迫真诚悔过。

赔偿须说明损害和因果关系，不能把全部情绪失望都换算成人时。原件毁损、隐私泄露等损失可能无法完全修复，裁决须承认这一点；世界不能因为机器能复制外形，就假定损害已经消失。

### 2. 有余额而拒不履行

有效支付裁决作出并经通知后，可由执行人员通过系统划转依法可执行的余额。争议中的临时保全只能针对有具体证据支持的风险，限定金额和期限，接受迅速复核；不能先冻结一个人的全部生活，再要求他证明清白。

必须保留足以获得必要真人照护、基本社会参与及合理自主生活的人时额度。额度依实际需要评估，可申诉；不能只保护名为“补贴”的入账，而把亲友为必要照护赠与的人时全部扣走。后续收入只按有限比例执行，不得持续全额截留。

保护额度、比例上限和保全期限应由公开规则事先规定，个案只在规则范围内调整并说明理由。它们不是税，也不对所有人普遍抽取；只用于履行具体生效义务。

### 3. 没有余额，不等于欺骗

暂时无力支付时，可以分期、暂停执行或依规则减免。不得因“身体健康，明明可以出去干活”便认定其恶意；执行针对现有可支配资源，不针对法院想象中的劳动潜能。

本卷建议普通私人服务债务采用有限存续：原则上应在约定到期后两年内提出请求；无到期约定的，普通情形从服务完成后的合理付款期届满起算，债权人不得通过一直不催告无限推迟起算，明确约定延期及受阻救济另行处理。已及时起诉的请求不因审理耗时消失，但通常不能在终局裁决五年后继续执行。两年与五年是本方案的虚构初始参数，不是借用某国通行法律。法律援助须主动解释期限；未成年人、无法自主主张权利者及遭强制阻碍者的救济例外，由明确规则保护。

执行期届满，未清偿部分依法终结；蜕皮、部分付款、普通复查或债权转让都不使这段五年期限重新起算。法院不得通过重复确认旧债，制造事实上的永续债务。重大侵害赔偿与刑事追诉期限另有规则，不能套用普通服务债务期限。

这里参考的基本权利底线是：不能仅因无力履行合同义务而监禁。它不等于蓄意欺骗、伪造证据或伤害他人均无须负责。[资料：《公民权利和政治权利国际公约》第 11、14 条](https://2covenants.ohchr.org/About-ICCPR.html)

### 4. 赠与自由与故意转移余额

自由赠与和完整传承仍然有效。不因一个人负债，就禁止其全部人际往来；也不因收款者是亲属，便推定串通。

若有证据证明，某项转移是为了逃避已经存在、本人知情的义务，法院可在必要金额内审查该转移的效力，保障受赠者陈述与申诉。追回不能重复计算同一笔债务，也不能把与案件无关的受赠财产一并拿走。善意受领者的保护及继承中的债务处理，需要与后续继承规则衔接。

蜕皮不自动免债，也不自动加重债务。记忆封存、遗忘、人格变化不单独构成恶意证据；是否存在欺骗，仍须证明具体行为。

### 5. 公共救助不替一切私人失约买单

受害者可以因现实照护、安全和基本生活需要获得公共帮助，即使责任人无力赔偿。救助资格不以胜诉或愿意和解为前提。

但公共系统不保证每一次私人有偿委托都能全额收回。若特定救助已经覆盖某一项可量化损失，后续赔偿须清楚结算，避免同一损失重复支付；独立的基本生活保障不因获赔而被一概收回。串通制造假案，不能成为系统新增人时的渠道。

## 六、严重侵害：保护先行，修复不能代替边界

### 1. 民事欠款与犯罪分开

欠款、服务失败或对质量有争议，都不能直接叫作诈骗。刑事欺骗须证明行为人具有相应欺骗行为和主观要素，并达到更高证明要求。本卷采用：普通民事争议按证据优势判断，刑事定罪须排除合理怀疑；举证规则不得因为 AI 给出高置信分数而降低。

刑事调查、提出指控、辩护与裁判分由不同人员承担。被指控者有权知道指控、获得独立辩护、质疑证据和保持沉默，不能被迫自证其罪。严重事件不能由社区人气投票决定。

### 2. 明确承认有限的强制权

本卷建议把旧设定“完全没有警察和暴力机器”修订为：没有军队；没有不受司法监督的常设强制权力；存在职责明确的专业保护与执行队伍。其功能确实包含现实警务和司法执行的部分工作，不能靠换名字假装不存在。

正在发生的人身侵害可以被及时制止。保护人员优先采取隔离现场、护送离开、限制接近等低伤害措施；确有必要时，可以使用与现实危险相称的强制手段。AI 设备可以辅助执行，但不得自行扩张授权或决定长期拘禁。

紧急限制人身自由必须记录理由，并在二十四小时内交独立人类裁判者审查；期限届满没有合法继续依据，应当释放。非刑事的紧急保护安置最多七日，不能以连续新开七日命令绕过上限；之后若需刑事羁押，须满足独立的犯罪嫌疑与程序条件，若需其他非自愿照护，须进入独立的能力、必要性与权利审查程序，不能仅凭危险预测续住。

限制接近等持续保护令也须有到期日，延期需要新的具体事实和重新听取意见。任何非自愿照护限制均设到期日，机构须主动申请独立复核，并证明当前具体需要及较轻替代措施不足；未经有效续期即终止，不得仅因既往诊断、身份或拒绝配合而续期。刑事羁押及刑罚的期限必须由行为发生前已经公布的法律规定，并可申诉；本卷不编造完整刑罚表，也不允许用“直到他真正变好”为无限关押理由。拒绝道歉、拒绝治疗或拒绝参与修复会谈，本身都不足以证明继续限制自由的必要性。

权力滥用由独立于执行队伍的机构调查，受害者有权获得救济。生存、医疗、续命、基本照护和人格尊严，在限制自由期间仍有保障。

程序保障借鉴《公民权利和政治权利国际公约》第 9、14、17 条；二十四小时、七日以及本世界机构安排是本卷设计选择，并非对条约具体时限的转述。[资料：条约正文](https://2covenants.ohchr.org/About-ICCPR.html)

### 3. 修复会谈是另外一扇门

在基本事实和责任具备适当基础后，可以由受过训练的人分别评估安全与自愿性，再邀请双方参与修复会谈。受害者可以带支持者，也可以通过书面表达而不与对方见面；任何一方都能退出。

会谈可以讨论发生了什么、损失是什么、怎样补救和避免再次伤害。不能要求“为了社区和谐就算了”，不能用公开羞辱迫使认错。调解员认为存在胁迫或危险时，应停止会谈。

履行修复协议可以成为裁判考虑的事实，但受害者不参加，不应使案件受到较差处理；付款多、口才好、表现得更会道歉，也不能购买免罪。社会对严重侵害的公共责任，不由私人和解自动消除。

新西兰司法部介绍的刑事恢复性司法程序强调自愿参与、安全评估和可以取消，报告交由法官在量刑时考虑；该程序通常在认罪或被认定有罪后进行。本卷借鉴其分工，不把这一前提套给所有民事调解，也不声称所有纠纷都适合面对面会谈。[资料：How restorative justice works](https://www.justice.govt.nz/courts/criminal/charged-with-a-crime/how-restorative-justice-works/)

## 七、这个世界特有的两类当事人

### 1. 未成年人和学徒

以现有设定中的成年标准为基础，未成年人可获得适合其理解能力的说明和独立协助。师父、监护人与案件有利益冲突时，不能同时代表孩子决定是否和解。

青少年承担什么责任，应考虑年龄、理解能力、授权范围和指导者义务，不把成年专业者的全部风险推给学徒。不能通过“你很成熟”或者“你记得前一段人生”跳过资格认定与保护。

### 2. 接近或已经跨越界线的机器

是否跨越智能界线，本身可能发生测量和解释争议。被检测对象至少具有针对不可逆处置的程序地位：获知理由、质疑证据、获得与其所有者和制造者无利益冲突的代表，以及请求复核。

已有可表达意愿的机器，应当被直接听取意见；不能默认由所有者替它选择清空、回滚或放逐。涉及主体性的争议，不能因为“尚未证明是主体”就先销毁它，使申诉变得不可能。

自告知拟作不可逆清空、永久关闭或同等后果的处置起，须保留实际可用的异议申请期；期间及复核期间原则上停止执行。独立协助尚未落实，不得据此认定机器放弃异议。存在立即危险时，优先采用可逆的隔离、权限限制和独立保全；任何不可避免的紧急干预仍须符合必要性、最小损害和事后独立审查，不能把紧急权限变成常规销毁渠道。

这不等于已经赋予所有设备完整公民身份，也不自动废除既有界线政策。本卷增加的是不可逆处置前的程序保护，并要求修订旧稿中“必须清空”与“由机器自己选择”相互冲突的条款。界线政策本身是否正当，仍可以成为人物和社会争论的问题。

## 八、可以直接写进小说的案件

下列为情境样例，不自动加入角色既定经历或季纲。

| 情境 | 司法怎样处理 | 仍然留下的人情问题 |
|---|---|---|
| “不用给，我顺手帮你。”对方修好后连谢谢也没说 | 不自动判给服务费；当事人可拒绝今后继续帮助 | 付出是否值得，法院无法替他决定 |
| 明确答应修好后给两个人时，事后声称“朋友怎么能谈这个” | 核实约定和履行，成立则支付；友情不能撤销承诺 | 收回报酬之后，友谊可能已经改变 |
| “回头不会亏待你。”双方对这句话理解不同 | 结合上下文判断是否有偿；含糊表达不能单靠时长补成债务 | 说的人可能真诚，听的人也可能真诚 |
| 学徒修了二十小时，远超原先约定 | 核实任务范围、经验告知和追加同意，不自动支付二十人时 | 老师要面对自己是否把风险留给了孩子 |
| 客户确实欠两个人时，但现有余额只够必要照护 | 确认债务，保护必要额度，分期或到期依法终结 | 服务者的损失不会因对方并非恶人而消失 |
| 名望很高的邻居把一笔已知欠款对应余额转给熟人 | 需具体证明规避义务，不凭人气放过，也不凭熟人关系推定 | 一段赠与可能同时带有爱与逃避 |
| AI 摘要漏掉“如果没有修好就不收费” | 回到原始通信纠正摘要；已经作出的错误决定依法救济 | 人们需要重新学习怎样信任机器 |
| 旧照片原件被粗心损坏，机器复制品几乎相同 | 调查注意义务和损害，不能宣称复制后损失必为零 | 有些东西的价值来自曾经发生过的生活 |
| 社区希望受害者在庆典前接受和解 | 可以拒绝；独立保护和裁判继续进行 | 温柔的集体期待也可能形成压力 |
| 一个可能跨界的机器，在复核前被要求立即清空 | 暂停不可逆处置，独立审查证据与表达意愿 | 程序可以争取时间，却不能替社会解决全部伦理矛盾 |

## 九、与旧稿的衔接及剩余边界

本卷形成可用于日常服务纠纷的制度骨架，并给出严重侵害与不可逆处置的基本保障。它不是完整法典，也没有证明这种社会在现实中一定运行成功。

| 旧稿内容 | 后续同步方向 |
|---|---|
| 付费蜕皮、蜕皮贷、按偿债能力续命 | 按作者决定删除，以免费续命替代 |
| 蜕皮清算、继承限额、服务税 | 按作者决定取消；保留余额连续和赠与、传承 |
| 真实服务即产生人时、绝无通胀 | 区分私人转账与公共发放；总量与发行另行闭合 |
| 所有服务均有时长保底 | 依本方案改为区分无偿、赠谢、有偿，时长不能独立创设欠款 |
| 债随人永久存在、通过服务换取免债 | 增加有限执行和依法终结；劳动抵债只能自愿 |
| 抹去记忆即构成最严重逃债 | 取消自动推定，证明具体欺骗或规避行为 |
| 透明账本使腐败不可能 | 改为可审计、可质疑，承认伪证、偏袒和程序滥用仍会出现 |
| 无警察、无任何强制机构 | 依本方案明确有限保护与执行职能及外部监督 |
| 界线后的自我选择与维修后强制清空 | 明确程序地位、停止不可逆执行和复核，消除冲突 |

完整继承的触发条件、善意受赠者与债务的关系，公共人时的来源，刑事罪名与有限刑罚表，以及各程序的具体期限，需要在对应专题中继续完成。保留这些边界，不影响小说先围绕承诺、证据、执行与修复展开日常案件；涉及其边界的剧情则应先补足规则。

这套司法允许人不够慷慨，也允许关系无法修复；但不能把欺骗叫作自由，把强迫宽恕叫作善良，或把一个人的余生当成另一人的偿债资源。
