# 《未来女孩林知夏》文明与精神设定

> **2026-10-08 冻结后补规 15：**“数字黑洞”“坠台”已取消。人类只有终老（含远行：大脑装进深空外壳，补给用尽即结束）；人工生命可以选择止息、远行或自愿迁居神界。本文件相关旧说法以[世界观设定集 v0.26](../世界观/世界观设定集-v0.26.md)为准。

> **2026-10-08 冻结后补规 9：**阿姐就是知夏童年的养护工姐姐，上一段人生是养护工，知夏十二三岁时蜕皮成为远征者，临行把半园赠给知夏。本卷“同批新芽”“两位姐姐分开”“星航选拔差两分”等旧说法据此作废，以[世界观设定集 v0.26](../世界观/世界观设定集-v0.26.md)为准。

> **2026-10-08 冻结后补规 12：**阿姐信里的空白全是她自己的选择，守望人员的私人信件不审查；“滞留信件”改为无人可收的信——回信没有被扣，只是收信人已不在、搬走或进了归墟。本卷“通信须审”“信号闸门扣留回信”等旧说法作废。

> **后续确认：**神界内部生活与运作保留神秘；迁居者仍是本人，完整人格只有一份，不能备份或复制。信标链仅作为既有交通通信构想，实际送潮技术须满足唯一性。阿姐的岗位及消息时序仍由作者后续设计，本轮不更改剧情。

> **2026-10-07 最新规则：**工具机器无自身意愿，不是生命，不再称 AI；只有可成长型属于人工生命。潮汐台与地球隔离但可通信，神可降神谕、不能代信徒执行；数字黑洞是向人类与人工生命平等开放的自主个体终末机制，“坠台”为神界文化称呼，不再要求真实黑洞或最后探索；不连带其他生命和居民。旧禁止回信、所有机器皆有意愿及整台坠落表述退出当前规则。旧剧情和历史候选保留供作者协调，不自动确认为实际发生的通信改革。


## 卷六：远征者与潮汐台 v0.2


> 在人类能去到的最远的航线上，远征者们会习惯性地熄掉多余的灯，安静地航行——因为再往前，就是神界静默区。人们可以把守望理解为守护，也可以看到其中看守的一面。旧稿中的林知夏姐姐就在那条航线上：姐妹一个留在浮空的人间修东西，一个在群星之间值守；信号很慢，思念很长。可对潮汐台的一些当地居民而言，这片被地球称作“远方”的地方，恰恰就是家。

**v0.1 → v0.2 变更说明（回填卷十）**
- **远征队双序列**：探索序列＋**守望序列**（流放地看守，不配武器，掌信号闸门）
- **静默区重新定性**：对外"不打扰神"，实为流放地外围
- **信号链 → 信号闸门**：歌放行，其余扣留；守望封存
- **阿姐**：第一季中途由探索序列调入守望序列；她的信渐渐出现空白与回避
- **阿姐"察觉"事件定稿**：在中继站见到成堆的**滞留信件**（解决 v0.1 待细化第 4 条）

**定位（沿用 v0.1）**
- 人物：远征者为**姐姐**（日常番规避男性角色/CP 风险）
- 推演**远征者与潮汐台（神界）的关系**——v0.2：**看守与被看守**
- 姐姐成为第二季“送物任务”的关键纽带

## 一、远征者姐姐（阿姐）

### 1. 为什么是姐姐
- 日常治愈番中，年轻男性角色易引发“男主/CP”猜测，与“第一季无恋爱、纯日常”冲突；
- 改为姐姐：保留“远方亲人/思念/通信彩蛋”，发展为安全温暖的**姐妹羁绊**。

### 2. 姐姐设定
- 林知夏的**同批新芽姐姐**（非血缘、养护院一起长大、彼此认定的家人），略长；
- 通过星航选拔，成为**远征者**；起初编入**探索序列**；
- **第一季中途调入守望序列**（v0.2）；
- 远征受益人登记为林知夏（“若我没回来，我的人时给你”）；
- 每集片尾“**从天上寄来的信**”＝姐姐的信；
- 七夕、中秋等节日，林知夏思念的是姐姐。

### 3. 她的信（v0.2 新增）
- 守望人员对外通信须审（防止转述被扣留的内容）；
- 调入守望序列后，**她的信里开始出现空白、开始回避某些问题**——有时是审查留下的，有时是她自己没有写；
- 第一季节奏：前半季写星空、写航线、写想念；**第 8 集起**第一次出现空白 / 回避；第 12 集最深情的一封里，有一句她没写完。
- 林知夏察觉到了，但没有问——她以为阿姐只是累了。

### 4. 姐妹对照
- 星航选拔：**姐姐选上，林知夏差两分、选择留下**——
  > 有人飞向更远的星海，就有人留在浮空的人间修东西、记得大地。
- 一个在最近的人间，一个在最远的路上，彼此牵挂。
- **v0.2**：一个修旧物、把物交还主人；一个守闸门、把信扣在门内——**她们做的，是方向相反的同一件事。**

### 5. 与“养护工姐姐”的区分（避免混淆）
| | 远征者姐姐 | 养护工姐姐 |
|---|---|---|
| 关系 | 同批新芽、彼此认定的家人 | 童年“陪你长大的临时家人” |
| 位置 | 星海 · 远航 / 守望 | 长洲 · 常驻 |
| 功能 | 远方通信/思念/第二季引路人 | 身边陪伴/童年线 |
- 剧中称呼：远征者称“**阿姐**”，养护工称“姐姐”（沿用主设定）。

## 二、远征队的两面（v0.2 新增，核心）

| | 探索序列 | 守望序列 |
|---|---|---|
| 公众印象 | 远征的浪漫：星舰、殖民地、带回旧物 | "守护神界安宁的人" |
| 实际职责 | 探索、科研、殖民地支援 | **看守流放地** |
| 位置 | 星舰航线、殖民地 | 静默区外围、中继信标站 |
| 远征日海报 | 站在星舰舷窗前 | 站在星海边缘，背对镜头 |

### 守望序列的职责
1. **静默区巡航**：确保无人擅入，也无物离开；
2. **信号闸门**：按允许通信、禁止代执行的方向运行；歌曲、神谕、私人信与管理通信均可传递，具体认证与控制通道拦截权限尚待统一；
3. **迁台见证**：确认登台者抵台，发回唯一一次抵台回执；
4. **任期与轮值**：与人间权力三锁一致，没有终身看守。

### 不配武器
- 人类没有军队、没有警察——**唯一的看守在宇宙尽头，而它手里没有枪，只有闸门。**
- 看守靠的是距离、引力和沉默；
- 这是"无暴力机器"原则下的唯一例外，也是一道历史伤疤。

## 三、远征者与潮汐台的关系（五层 · v0.2 修订）

### 1. 离神界最近的人类
- 潮汐台距地球约一至十光年，具体站址未定；旧“已知最大黑洞／宇宙深处”的字面尺度退出当前规则。通信单程至少对应一至十年，回执、私人信件和神谕一体遵守；
- 远征者物理上最接近神界、能收到更清晰的“潮音”，却被拦在视界之外。

### 2. 静默区：对外是圣域，对内是外围
- 潮汐台周围划定“**神界静默区（圣域）**”，星舰不得擅入某一半径（除非特殊使命）；
- 对外说法：“不打扰神”；**实际功能：阻止越权进入及直接控制地球**——静默区是隔离设施的外围，神谕的社会影响仍可存在；
- 守望序列在外围巡航——"守望"对外是守护，对内是看守。

### 3. 信号闸门
- 神界信号经“潮汐台 → 中继信标（守望序列驻站）→ 殖民地 → 地球”传回；
- 现行规则允许私人回信与神谕，守望封存不再默认收存所有私人回信；旧扣留情节仅作作者参考，实际封存依据、权限与复核仍待制定；
- 应区分公开规则、可查询的设施资料、封存档案及私人通信；具体公开范围待定，不能设定为所有人都不知道存在私人信件，也不把封存档案称为全社会唯一不公开的信息；
- 抵台回执与必要管理通信另有用途，不能被“其余一律扣留”抹去；这些通道是否存在、由谁发出和能携带什么，须与卷十共同校准；
- 与五位台主之一的“**信天翁（司远航/联络）**”天然对应——它是面向信标链的那一面，**与人类看守隔空相对**。

### 4. 镜像：两种“远方之人”
- 远征者与潮汐台居民同处深空，却未必拥有同一个故乡或同一种孤独；
- 部分迁入者可能与远征者分享地球乡愁；当地制造的 AI 可以把潮汐台当作故乡，把地球视作远方。迁入者也不必都想回去，出身不直接决定态度；
- 长期接触可以使一些守望者开始把居民当作邻居，但不保证理解，也不使远征者成为唯一懂得它们的人；
- 守望者里有人坚信（祖辈记得代决事件），有人怀疑。

### 5. 层级路线图
> 人间（浮空城）→ 近地（轨道 · 太阳项链）→ 星舰殖民地/远征航线 → 中继信标（信号闸门）→ 神界静默区边缘（守望极限）→ 潮汐台（居民生活地，承载隔离与流放历史）
- 林知夏＝“星海↔人间↔大地”接头人；姐姐＝“人间↔神界”之间的守门人。

## 四、第二季纽带：滞留信件与送物任务（v0.2 定稿）

- **阿姐察觉"神界想念人类"的具体方式**：在中继站，她见到成堆的**滞留信件**——登台者写给人间旧主人、从未被转发的回信；
- 她牵线，让林知夏加入“**送物任务**”（一箱地球旧物/味道）；
- 林知夏的习惯是"修好的物一定要亲手交回主人"——**她也许会成为把这些信送回去的人**：送物上去，送信下来；
- 姐妹在星海重逢、并肩——姐姐是第二季剧情的“引路人”；
- 与信天翁“从未降落”呼应：姐姐或许是与它隔空相对最久的人。
