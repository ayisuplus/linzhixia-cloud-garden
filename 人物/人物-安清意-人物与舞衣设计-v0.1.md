## 二、人物形象提案

**一个爱笑、说话明快的少女，穿上轻纱舞衣以后，动作和袖影带出仙气。**

面容保持十五岁的青春感：略圆的面颊、灵动杏眼、舒展的眉形、自然明亮的笑容。与知夏同框时，用更外露的笑意和爽朗姿态区分；不更改知夏身份或配色。深棕近黑头发，发量和发丝精细度沿用同一 CG 美术标准。

性格的可演表现建议：介绍鞋时直接说是妈妈传来的；谈到跳舞时眼神亮起来；试穿能够明确指出哪一处仍不舒服。磨坏珍惜的鞋可以有一瞬懊恼，不把一次磨损扩大成罪责或家庭冲突。这些是表现建议，不新增对白定稿。

| 部分 | 首版建议 | 画面目的 |
|---|---|---|
| 主轮廓 | 合体交领上衣，接轻盈长裙，腰线清楚，裙身便于展开 | 静止时看清人物，转身时形成轻柔弧线 |
| 配色 | 暖白底、淡杏与浅竹青层次，少量朱砂与淡金点缀 | 按作者要求取消紫色，保留轻盈与暖雅的中式配色意向；具体采用仍待看图 |
| 面料 | 内层不透的细腻绢感布，外层轻纱；颜色在层叠处自然变深 | 以材料厚薄产生轻盈与体积，保持同一细腻 3D CG 画风 |
| 袖子 | 贴合上臂的袖身，腕部接柔软水袖，末端逐渐过渡到浅竹青 | 抬手、回身时形成主要飘逸线条；长度随舞段核对 |
| 裙摆 | 层叠轻纱，前片略短、后片稍长，以踝部为尺度，不做落地拖尾 | 转身或走步时能露出鞋尖和脚步；具体下摆随动作验证 |
| 腰部 | 简洁腰带、两条轻短绶带 | 帮助观察腰身转向，不堆叠悬挂物 |
| 纹样 | 肩襟或裙身局部稀疏小花与细线绣，第一版不满身重复印花 | 留出纱与袖子的可读空间，花种待看图选择 |
| 发型 | 高位盘髻配简洁编发收束，少量贴面碎发 | 保留少女气质，能看清转头和肩颈 |
| 发饰与妆容 | 小花簪、少量浅色珠饰；清透舞台妆，笑眼清楚 | 抬高舞台辨识度，不用大型冠饰和长垂坠遮脸 |

这一版集中使用轻纱、层叠裙与水袖。首版不同时增加扇、伞、长披帛等独立舞具；若后续选定舞段需要，再补相应设计。寄件、通话和试鞋的衣着状态由实际镜头决定，先完成这套重点舞衣的主形象，不一次生产完整衣柜。

水袖的动作参考：[北京舞蹈学院《中国古典舞袖舞》课程说明](https://www.bda.edu.cn/xxyw/6211.htm)强调身与袖的配合。本方案只借用这一设计原则；不是照搬课程动作或某个演出服，也未完成编舞。袖长与最终短舞段须一起核对。

## 四、妈妈传来的舞鞋提案

**初步方向：** 暖白绢感鞋面、贴脚平底轮廓，淡杏小花、少量朱砂花心与青叶绣或细绣边，保留与现行舞衣相配的视觉关系。鞋型、底材、固定方式和舞蹈适用性尚待具体设计，不能从漂亮外形推定可以完成任何动作。

**损坏范围建议：** 优先选择反复接触部位的局部磨损，如鞋口包边磨毛／开线、内衬边缘翘起，沿用现有细纲的可见试样与试穿反馈。作者已确定磨坏原因，具体位置和程度仍待鞋型核对；不自动改为鞋底断裂、跳舞摔伤或整双腐坏。

**连续性：** 同一双鞋保留左右关系、花纹和损坏位置；原状、检查、修补中、修后逐项可对照。保留妈妈传下来的外观识别点，同时允许按物主同意更换影响穿用的局部。

鞋的具体年龄、原使用者与清意的尺码关系、哪些细节最令她喜欢均待明确。妈妈传鞋不等于妈妈去世；不新增亡亲、遗愿或强迫传承剧情。
