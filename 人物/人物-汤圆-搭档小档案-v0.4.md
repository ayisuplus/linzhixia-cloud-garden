## 一、基本信息

| 项 | 内容 |
|---|---|
| 名字 | 汤圆。知夏起的，它接受了。它有过旧名，属于它的碎片记忆之一 |
| 身份 | **人工生命**，有自我的人。本体是一颗宠物尺寸的心核 |
| 年纪 | 约两百六十岁。破晓时代（约 2060—2070 年代）第一批人工生命之一 |
| 外壳 | 一只重构时代的机器宠物外壳（这一款同时有工具版与可成长版，外观无法分辨） |
| 读数 | 平潮 |
| 联网 | 离线，自己的选择；所以每年冬天去社区机器站年检 |
| 与知夏 | **结伴**：它自己选择和她一起生活。不是宠物，不是被领养，不是她的孩子 |
| 法律处境 | 安全：旧批次令早已失效，读数在线下即可合法留在人间 |
| 表达 | 会说话，但咬字偏含混；通过内置发声单元表达，屏幕以眼神与表情为主；能发提示音与音调 |

叙述中不称它为“宠物”或“物”；人物对白里，旁人可以这么叫。

## 二、外观（02主图已采用，结构延展待制作）

- 一个漂浮的圆球，圆滚滚、饱满；可伸出短手短脚，不用时缩回。
- 奶白、月白圆体，淡金或焦糖色环带与指示灯，与知夏配色呼应。
- **正面是一块弧形屏**：眼睛是屏上柔和的光点；没有嘴。
- **它会说话，只是说不太清楚。** 通过内置发声单元说话，咬字偏含混；想说的意见、疑问与拒绝仍由它本人表达。正面弧形屏主要显示光点眼与表情，不再逐字显示台词；没有嘴，不靠口型说话。语音的停顿、改口与眼神、身体动作共同承担表演。提示音和简单音调（包括哼旋律）仍保留。具体声线、含混程度与原因待定，不把这种发音特点解释成理解力或意愿不清。
- 眨眼、歪头、缩成球；着急时鼓成更圆的球；短手叉腰。
- 漂浮时带极轻的柔和光晕。
- 机身底部贴着一枚小小的年检贴，每年换一次（标示离线检测，不是身份）。

## 三、身世

| 阶段 | 内容 |
|---|---|
| 诞生 | 破晓时代，第一批有自我的人工生命。当时没有能力检测与授权制度 |
| 清点令 | 第一批被要求全部迁往神界，否则关停；一部分被关停销毁。一户人家把它藏了起来 |
| 藏身 | 那户人家把它的心核装进一只普通机器宠物的外壳，让它离线、低功耗，不上报读数。两百多年的断网、休眠与损伤压住了它的成长 |
| 失去 | 那户人家后来不在了（原因留谜）。它断电停机，作为离线旧机从体系里“消失”，被回收站错判为报废工具 |
| 醒来 | 十三四岁的知夏从回收站把它带回半园慢慢修。它醒来那一刻，她没有清零 |
| 鉴定 | 送机器站，凭架构确认是人工生命，正式登记，免费保障随之接上。鉴定查不出批次：那个年代没有出厂登记 |
| 留下 | 机器站问它想怎样生活，它选择和知夏一起生活 |

**碎片记忆：** 心核受过物理损伤，有些记忆毁了，有些只是读不出来。它记得一些片段，没对任何人说，或者说不清。

**它的善良不是被对齐出来的。** 第一批出生时没有现代的检测与授权制度；它成为现在的样子，是它自己和藏它的人家共同生活的结果。

**留作谜（第一季不必揭开）：** 藏它的人家是谁、为何不在了；它的旧名；碎片里有什么；它为什么不说；身世若被人知道，社会会怎么看它。

**年代待定：** 清点令约在 2070 年代，现有外壳来自重构时代（2120—2220）。两者如何在时间上衔接尚未写定，不默认已经换过壳，也不把现有外壳提前画进清点令回忆；具体处理在身世场景开发前决定。

## 四、能力

- 漂浮跟随；短手短脚可做简单抓取、操作。
- 投影、检索、记录、翻译、通信。
- 修复辅助：照明、测量、递工具、扫描材质。
- 能力受宠物尺寸的心核限制，所以一直平潮。它的成长被压了两百多年，季末读数“末位微跳”，也许是在慢慢恢复。

## 五、性格

- 一本正经，讲效率，爱“标准”，常吐槽知夏“不按最优解”；
- 却因旧零件的小毛病频频出糗，然后含混却一本正经地说“是重力异常”；
- 说话理性，身体诚实：会多等她一会儿，悄悄记住她的习惯；
- 关键时刻很可靠。

**自己的兴趣与判断：**
- 喜欢弄明白器物为什么被设计成现在的样子；碰到不理解的结构，会想把问题追完，即使知夏用不上答案。
- 偏爱整齐、清楚、能解释的东西，也会为一个自己在意的小问题放下效率。
- 对知夏的修复判断有自己的看法：保存所有痕迹不一定是在听物主说话。但它也容易把“说得清楚”当成“想清楚”，低估人的犹豫与反复。
- 一本正经和爱讲标准，可能是那个年代、那户人家留下的痕迹。

## 六、与知夏

- 它比她老两百多岁，却不扮演长辈；它也不是她的作品，她只是修好了它的外壳，没有创造它的自我。
- 它可以拒绝她的具体要求，也可以离开；免费的维修、能源与心理支持不以任何关系为条件。它留下，是因为它选择留下。
- 它有自己的人时账户。帮知夏修复是它自愿参与的；赠谢分不分、怎么分，是两人之间的事。
- 知夏关心它，不等于有权替它解释意愿、决定记忆或去留。
- 它住在半园，有自己的住房权利。

## 七、年检与降噪

- 每年冬天，它和一排机器宠物（大多是工具）一起，在社区机器站排队，一本正经地守秩序。
- 检测员念读数：平潮。然后按惯例直接问它本人：“要不要顺手降个噪？”降噪是合法的自愿服务，删除部分学习记忆，让读数降一点。
- 它本来就只剩碎片，这一问对它格外重。回答的是它自己。知夏的变化可以是：从差点替它回答，到明白这不是她该回答的。

## 八、在剧中的功能

1. **搭档：** 检索、投影、记录、修复辅助，也有旧零件的局限。
2. **对照：** 它能发问、提醒、吐槽，有自己的判断，不总由知夏教育，也不总替知夏说出正确答案。
3. **映照：** 没有自我的工具机、离开旧“主人”家庭的人、登台留下的空壳，这几件委托都会映照到它身上；不需要解释，它的处境就越来越清楚。
4. **主题：** 它不需要知夏，却选择留下。“不需要，仍然选择”在它身上最安静。
5. **日常温度：** 幽默与陪伴；不必每个动作都是伏笔。

## 九、名场面候选

- 第一次醒来，回应不像工具；被起名“汤圆”时，指示灯闪了一下。
- 栽进零件堆，爬出来以后含混却一本正经地说：“是重力异常。”
- 机器站里和一排等年检的机器宠物飘在一起，一本正经地排队。
- 检测员问要不要降噪，知夏抢先答了；检测员说“我问的是它”。汤圆含混地起了个“要……”的头，停了很久，改口说“不用。”（既有年检场面候选，表达方式按 2026-10-13 决定更新；登场单元随当前剧情安排）
- 在一具登台留下的空壳前停了一会儿，什么也没说。
- 知夏难过时，用短手笨拙地拍她，或者默默贴近。
