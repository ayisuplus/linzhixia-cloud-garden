# 分镜脚本

把已定稿的单元剧情，拆成**场次卡 + 镜头卡**两层的分镜脚本，供 AI 视频工具逐镜独立生成，最终剪成日式电视动画。

首集当前是校园旧舞鞋方向，细纲与测时待做，可做可撤销的分镜预演；正片目标 17—18 分钟。怀表旧稿的 17:30 分场预算与冷开场不能直接作为新首集依据。不得把预演完成当作剧情或画面已定稿。

模板：
- [场次卡模板](场次卡模板.md)：每场填一次，放整场不变的信息。
- [镜头卡模板](镜头卡模板.md)：每个镜头一张，只写这一镜的内容与变化。

## 一、开始前必须读

1. 该单元的剧情文件（`第一季/第X单元-*-剧情-*.md`），分场、台词、动画化要点都以它为准。
2. [世界观设定集 v0.26](../../../世界观/世界观设定集-v0.26.md)：现行唯一权威设定。
3. [创作速查卡](../../../创作速查卡.md)：硬规则与写作守则。
4. 人物档案：[林知夏 v0.6](../../../人物/人物-林知夏-人物小传-v0.6.md)、[汤圆 v0.4](../../../人物/人物-汤圆-搭档小档案-v0.4.md)。
5. 若已有前面场次的分镜，读上一场最后一个镜头的“结束状态与继承事实”。

## 二、工作流程

1. **定场次：** 按当前剧情文件的分场，一场一个文件。先填场次卡，按动作、对白、笑点停顿与世界展示估时；模型单次生成长度按本批入口核实，不设通用 10 秒上限。
2. **拆镜头：** 每镜明确主要视觉任务，连续动作可以由长镜头承载；对白按反应、调度与节奏决定是否切镜。世界铺陈、生活感与喜剧停顿都可以是镜头功能。
3. **填镜头卡：** 按模板逐项填写，规则见第三节。
4. **自查：** 每场写完按第五节检查，问题当场改掉。
5. **交付：** 写进 `第一季/分镜/第X单元-第Y场-<场名>.md`；文件开头列出本场镜头总表（编号、时长、景别、事件一句话），再接场次卡和各镜头卡。告诉作者总镜头数、总时长，以及所有【待作者确认】的条目。

## 三、填写规则

1. **每个属性只填一处。** 模板已经去重：朝向只在“世界状态”里写，注意目标只在“世界状态”里写，摄影机参数只在“景别与摄影机”里写。不要在别处重复，避免前后矛盾。
2. **工作文档中没变可写“同上”。** 但以下几项每镜必须写全：镜头编号、时长、核心事件、动作执行链、结束状态与继承事实。交付独立云端提示词时，必须展开引用与“同上”，包含本镜实际需要的全部条件。
3. **整场不变的信息放场次卡**，镜头卡里不再重复，除非本镜有变化。
4. **台词一字不改。** 对白原文必须逐字照抄剧情文件。确实需要新增或改动台词时，标【新增台词，待作者确认】。
5. **画面内文字逐字写明，但一律后期叠加。** 木牌、信纸、终端界面、汤圆屏幕上的每一个字都要在镜头卡里写出来，只用简体中文；生成时不让模型写字，屏幕保持只有光点眼或一块空白发光区，后期合成文字。例外：需要锁定构图的实物文字（如“修旧物”木牌），先用生图画好首帧，再用图生视频，并要求“保持首帧文字不改写”。
6. **非人角色用它自己的表现方式。** 汤圆没有脸：情绪靠光点眼的形状、指示灯的明灭节奏、身体的鼓胀与收缩、漂浮的高度与速度来表现。
7. **汤圆的台词是屏幕文字。** 对白处理方式填“屏幕文字”；写明打字节奏（快打、慢打、停顿、删掉重打）与每个字出现的时机。一屏不超过约 15 个字，停留时间按观众阅读速度留足（约每秒 4—5 个字再加半秒）；长句拆成几屏。镜头必须拍得到它的屏幕，或给屏幕插入特写。
8. **对白处理方式要写明：** 正常／静音口型（有口型无声音）／画外音／内心独白／屏幕文字（汤圆）／无对白。以当前确认剧本为准，不由模板引入旧冷开场。
9. **可选字段：** “尸体数量”“皮肤材质参考”本作通常不用，可以不填。
10. **剧情文件没写的细节**（比如具体动作、站位），可以按设定合理补出；改变剧情走向的，一律标【待作者确认】，不擅自决定。

## 四、本作固定锁定（每一镜都适用）

**画面与风格**
- **日系治愈系 2D 手绘电视动画**：柔和赛璐璐上色、一到两层阴影；手绘水彩质感背景；低饱和偏暖，月白、米青、暖杏、焦糖、淡金为主色；光线柔和，充满希望。科幻元素造型圆润，融进生活，不冷硬。**以 2D 为主，2.5D 只偶尔用于远景浮空城与云海的视差点缀。** 完整风格锁见 `第一季/制作/第一单元-生成提示词-v0.1.md` 第一节。
- **工具（2026-10-10 作者更新）：** 图片在当前 Codex 对话中生成后导入 Toonflow，不使用已移除的 Codex 代理提供商。视频使用作者选定的 MiniMax H3；只准备完整提示词与真实参考并放入画布，由作者在云端手动生成、下载回填，不自动调用云端 API。具体 H3 版本、参数与参考能力按本批入口核实。视频生成时不带声音，声音全部后期制作。
- 默认画面比例 16:9。
- 生成与参考方式按镜头需要和本批云端入口实际能力填写；不默认所有镜头使用同一种参考模式。
- 园林“框景”是本作的视觉母题：每场开头优先用花窗、漏窗、门洞框住画面。

**人物外观**（以角色设定稿为准；未定稿前按以下文字）
- **林知夏：** 纤细灵巧；低马尾、有碎发为待采用设计；月白、米青为主，焦糖、赭石点缀；学徒围裙带多个工具小袋；立领、小盘扣。第一季五年间会长高、换发型，以该单元剧情注明的年龄和采用参考为准。
- **汤圆：** 漂浮的圆球，奶白或月白；淡金或焦糖色环带与指示灯；眼睛是柔和的光点；短手短脚，不用时缩回几乎看不见；底部贴一枚小小的年检贴；漂浮时带极轻的柔和光晕。**正面是一块弧形屏，光点眼显示在屏上；没有嘴，不说话。** 它的台词一个字一个字打在眼睛下方；能发提示音和简单的音调（会用音调哼旋律）。
- 其他人物（许伯、阿迟、阿姐等）的外观，写在各单元的场次卡里。

**默认禁止事项**
- 画面内出现英文、乱码或错字。
- 汤圆出现嘴巴、人脸或手指细节；汤圆发出说话的人声；汤圆的外观、颜色、年检贴位置在镜头间跳变。
- 任何人物的发型、服装、配色在同一场内无因跳变。
- 即时的跨星际视频通话（光年之外只能靠延迟很久的信件）。
- 末日废土、赛博朋克霓虹、压抑冷硬的机械感（违反主题定案）。
- 写实血腥、恐怖化的机器形象。
- 叙述性字幕把汤圆称为“宠物”。

## 五、每场写完的自查

- [ ] 每个镜头的开始状态，与上一镜头的“下一镜头必须继承的事实”一致（人物位置、朝向、服装、道具、光照、天气）。
- [ ] 屏幕左右关系与运动方向不越轴；越轴时有过渡镜头。
- [ ] 台词与剧情文件逐字一致；对白时长不超过镜头时长。
- [ ] 本场镜头时长合计接近剧情文件给出的时长。
- [ ] 没有违反 v0.26 与速查卡：机器服务不被写成劣质；降噪只问汤圆本人；没有即时跨星际对话；知夏与汤圆是结伴。
- [ ] 不可逆的变化（怀表开始走、年检贴更换等）在之后的镜头里一直保持。
- [ ] 所有【待作者确认】都已列在文件开头。
