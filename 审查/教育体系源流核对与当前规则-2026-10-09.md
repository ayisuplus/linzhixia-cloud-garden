# 教育体系源流核对与当前规则

日期：2026-10-09。回应作者对“定向学习”出处的疑问，并记录本轮逐步澄清后的规则。现行规则已回填[世界观 v0.26 第十节](../世界观/世界观设定集-v0.26.md)；本文件用于追溯与列出仍需设计的接口，不是第二份主设定。

## 二、本轮作者确认后的关系

1. **每名学生自主选课、自己排课。** 不存在助手此前提出的“公共基础课＋另选专业课”制度二分。
2. **每一种课都有机器版与真人版，逐门选择。** 机器版基本随到随学；真人版名额有限，需要付费报名。免费机器支持与人时计费沿用现有世界规则。
3. **真人教学不只用于手艺课，机器教学也不只用于知识课。** 不写成机器教不了实践、情感或成长支持。
4. **知夏的真人旧物修复班老师，就是她的师傅。** “修复班”是共同选修该门课的学生群体，不等于一整天共用课表的行政班。
5. **学校是一个容纳多个学习小院的大院。** 工坊院是学习场所，可以设在学校内。具体建筑位置、与城市匠作园的关系仍待设计。
6. **知夏的三个学习重心确定为旧物修复、星海导论、古典舞。** 作者明确保留阿姐远征经历对星海兴趣的影响，并从传统艺术候选中选定古典舞。修复课的真人师傅已定；另外两门的教学方式、古典舞内容及起始水平仍未确定。三个重心不是总选课数上限。

作者先用“补习班付费报名”作类比，随后明确不存在公共课分类，并进一步确认每门课都可选机器或真人。本记录以最后的完整说明为准，不把中间的表述单独冻结成另一套规则。

## 三、撤回的助手补设

- 撤回学校公共课老师与修复师傅必为两人的建议；不能为了校园戏再复制一个老师角色。
- 撤回常规班由公共体系负担、课外才私人付费的推荐；作者选择的是名额有限、付费报名的真人版课程。
- 撤回把“定向”当成已经完整设计的统一分流制度。名称是否保留及年龄分段的作用，须在自主排课规则下重新检查。
- 不把“工坊院可以在学校里”写成师傅已经搬迁，或认定学校与匠作园是同一地点。

## 四、需要补齐的最小接口

| 问题 | 已有边界 | 尚需决定 |
|---|---|---|
| 年龄与学习进度 | 知夏首季十五至二十岁，二十岁成年；个人自行排课 | “筑基／定向”是否保留，年龄和课程进度如何对应；不能自动恢复锁轨或蜕皮重读 |
| 报名与持续上课 | 真人版付费、限额；机器版基本随到随学 | 课程周期、名额分配、能否中途加入／更换方式；不先指定抢课、考试、启智分或抽签 |
| 费用与退出 | 沿用人时，按报名约定获得课程指导；不等于买下老师 | 知夏报名人时来源，取消与未授课部分如何处理；课外指导包含范围 |
| 教室与同学 | 学校内有不同学习小院，同门课形成相遇 | 真人与机器版本是否共用场地、同学哪些人反复出现、汤圆以何种方式参与 |
| 修复实践 | 练习与真实委托应区分，未经物主同意不改物；超出能力停手 | 教学用物由谁提供；实践指导、物主知情与补救安排，首次校园情节涉及的部分先定 |
| 成长与资格 | 不因成年自动获得技能，不把私人拜师当成受教育门票 | 学习完成如何评价；尚无完整职业认证制度，不能自动新增证书或发证机关 |

人工生命学习、成年后再学习、蜕皮后的课程衔接另外保留接口，不把全部社会教育细则塞进首集。

## 五、对首集设计的约束

- 作者已把首集方向改为学校中的青春日常，由老师或同学的修复事项带出城市；修什么、谁提出、结尾怎样使用仍未定。
- 师傅可以在修复课上出现，第一集不再靠“去找另一位老师”强行穿城。
- 同学从共同上课、练习与相处中产生，不为校园氛围预设统一行政班。
- 旧《半园的第一位客人》的 17:30 分场表只属于怀表旧稿，不能直接作为校园首集的制作预算。正片 17—18 分钟目标仍保留。
- 城市与校园的空间草案可继续讨论；正式分镜前先明确本集实际使用的教学场所、物件与课程关系。

本轮没有代写首集剧情、生成媒体或修改画布。
