# 司法制度：资料依据与对抗性审查

日期：2026-10-07

对应设计：[文明与精神·卷十一：司法与修复 v0.1](../文明与精神/文明与精神-卷十一-司法与修复-v0.1.md)

## 一、研究问题和资料边界

本次受作者委托调查司法资料，并为虚构社会设计制度。重点是私人服务可以自愿、不以生存逼迫劳动的前提下，怎样处理承诺、失约、损害与救济。

以下均为官方发布的第一手资料。外国司法程序、国际条约和伦理指导各有适用范围；它们提供制度参照，不自动成为这个世界的法律。本研究不是现实个案法律意见，也不是恢复性司法成效的系统综述。

## 三、本轮设计选择与依据

### 1. 非强制收费，不等于所有承诺都无效

作者此前尚未决定明确报酬承诺是否必须兑现。本轮选择“可以无偿，但有效的有偿约定可以执行”。这样既保留赠谢和人情灰度，也使司法有可以认定的义务。该选择是受托设计，不是补写作者过去的回答。

私人报酬采用余额转账；公共服务由系统依公共规则发放。若改为系统对每次私人劳动都新增人时，失约案件的受损结构、串通风险及总量机制将发生变化，必须重新设计，不能混用两套账务前提。

### 2. 恢复性司法是可选路径

自愿修复适合某些人和某些案件。事实争议、权力悬殊、持续危险或当事人不愿见面时，正式裁判与保护仍然存在。不能把“社区和谐”变成迫使弱者撤诉的理由。

### 3. 执行能力必须诚实入设定

账户划转、限制接近和制止现实伤害都含有强制性。旧稿“没有任何强制机构”无法与这些功能同时成立。建议保留无军队的方向，承认有限专业执行职能，并把监督、申诉及权力边界写清楚。

### 4. 连续人生，不推出无限债务与无限污名

蜕皮不自动清账；普通债务仍可依一般制度终结。二年请求、终局后五年执行属于本轮虚构参数，有明确救济例外，且不得靠蜕皮、少量付款或复查重启执行期限。它不适用于所有侵害和刑事案件。

### 5. 不替尚未完成的其他制度作假闭合

无税公共发放的人时来源、继承规则与完整刑法仍需专题设计。司法岗位计酬方式、私人支付来源与执行原则已写出，但不能因此声称经济总量、所有犯罪后果和所有继承争议均已解决。

## 四、独立对抗性审查记录

按作者要求，分别由 institution_review 与 boundary_review 两个独立审查代理提出反例。第一轮在成稿前检查制度漏洞；第二轮针对成稿复查。下表记录第一轮发现及设计中的处理，随后记录第二轮结果和补丁。

| 反例或漏洞 | 已纳入的处理 | 仍需保留的边界 |
|---|---|---|
| 私人假委托、假诉讼套取公共补偿 | 判决不新增人时；公共救助不保证所有私人报酬；同一损失不得重复赔付 | 公共发行账务另行设计 |
| 欠款后赠与全部余额，合法逃避执行 | 针对知情既存义务的故意规避，可以个案审查；限定金额、保障第三人陈述 | 善意受赠与继承细则尚需衔接 |
| 不断复查和少量付款，使债务永远不结束 | 固定有限执行期，禁止通过蜕皮、复查、部分付款重置 | 重大侵害另设规则，不套用普通债务期限 |
| 法院认为能工作就有能力偿付 | 仅执行现有可支配资源；不得要求劳动抵债 | 保护额度需公开制定并可申诉 |
| 只保护补贴账户，把必要照护赠款扣尽 | 按实际必要需求保护额度，后续收入也不得全额持续扣留 | 本卷没有凭空设定全社会照护单价 |
| 学徒无限延长工作，要求客户照时付款 | 区分范围、计酬方式、合理工时与追加同意 | 服务技能系数仍由其他制度定义 |
| 社区通过罢免或投票干预正在审理的案件 | 资格训练、随机分配、回避、跨社区复核和独立纪律程序 | 现实执行效果不能仅凭条文保证 |
| AI 没作最终裁判，却通过筛选材料决定结论 | 摘要追溯原件，可质证缺失与误读，无记录也可主张权利 | 不声称机器记录绝对真实 |
| 临时保护反复续期，实际成为永久拘禁 | 二十四小时独立审查、非刑事紧急安置七日上限，禁止连续重开；其他程序需独立条件 | 完整刑事羁押、刑罚及能力审查规范尚未展开 |
| 所有者代机器选择清空，申诉尚未开始主体已经消失 | 独立代表、直接听取意愿、暂停不可逆处置、优先可逆隔离 | 不自动解决所有机器公民身份争议 |
| 无限寿命使过错永远公开、案件永远重来 | 普通复核后终结；再审严格限定；禁止全民道德分与永久欠账名单 | 档案保留、封存和删除年限另行细化 |

第二轮成稿复查已完成，两位审查者均认为方案可作为日常小说制度草案，普通服务纠纷部分无阻断项；不将这一结论扩大为完整法典或现实制度的有效性证明。成稿审查提出的三项补丁已逐项写入：

| 审查者 | 成稿中的漏洞 | 最终补丁位置与内容 |
|---|---|---|
| institution_review | 无付款到期约定时，债权人可以几十年不催告，使有限期限迟迟不启动 | 第五节第 3 项：普通情形从服务完成后的合理付款期届满起算，不得因一直不催告而无限推迟 |
| boundary_review | 七日紧急安置结束后转入非自愿照护，后续仍可能无限持续 | 第六节第 2 项：照护限制也有到期日，机构主动请求独立复核，证明当前需要及较轻措施不足；未有效续期即终止 |
| boundary_review | 机器获知处置后、尚未正式提起复核前，可能已经被清空 | 第七节第 2 项：从告知拟处置起保留实际可用的异议期，期间暂停执行；独立协助未落实不能视为放弃异议 |

补丁后由主审逐项核对其落点，并检查三份关联文档的本地链接及 Git 差异格式。独立审查结论针对其收到的成稿，未将主审补丁核对冒称为第三轮独立审查。

## 五、如何理解本次成果

这是一套经过资料比对与反例检查的虚构制度草案。核验目标是概念不偷换、规则不直接互相冲突、典型纠纷有处理路径；不把桌面推演说成实际社会运行验证。

后续主设定同步时，应连同免费续命、余额连续、无税方向一起更新，并明确区分作者已确认原则与本轮新增制度选择。旧版文档保留，避免覆盖世界观演变记录。
