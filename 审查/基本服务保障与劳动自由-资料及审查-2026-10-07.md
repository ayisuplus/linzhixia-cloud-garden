# 基本服务保障与劳动自由：资料及审查

日期：2026-10-07

**适用结论已撤回。** 作者明确：所有基本服务，包括心理服务，机器均能免费完成，任何人不必为满足基本需要依赖他人。本次研究错误地把现实中的必要真人供给当作本世界前提。下文资料和历史审查记录保留，但不能用来支持在本世界建立“必要真人保障”制度。独立审查未发现内部阻断项，不等于验证了前提适配性。更正见[卷十二 v0.2](../文明与精神/文明与精神-卷十二-机器保障与自愿人时-v0.2.md)。

对应方案：[文明与精神·卷十二：公共保障与自愿服务](../文明与精神/文明与精神-卷十二-公共保障与自愿服务-v0.1.md)

## 一、研究范围

作者已经确认人时不应产生强制劳动，随后委托深入调查基本法律与运行方式。本次问题是：必要真人服务能否获得公共保障，同时不征用任何具体人的劳动？

结论是可以设计相容的权利和组织结构，但无法仅凭法律条文保证任何时刻都有人可用。公共机构要承担实际安排、公平分配和补救责任；自愿供给的规模仍是需要验证的世界设定前提。

研究以官方条文、政府指导、职业监管指引及 WHO 报告为依据，不把外国法律直接拼装成普遍适用的现实法，也不将后稀缺社会方案称为已经验证的现实制度。

[官方页面](https://www.ilo.org/topics-and-sectors/forced-labour-modern-slavery-and-trafficking-persons/what-forced-labour)

## 三、推理链及排除的简化答案

1. 有需要的人获得保障，不意味着一个具体人丧失拒绝权；应由公共机构组织多人的自愿参与。
2. 公共安排不能只发凭证，还须落实合格、适配、可达的服务；必要性按本人处境判断。
3. 承诺服务的机构需要储备、替补和跨区接续。若人人随时可能退出，就不能保证任何时刻所有需求当场满足。
4. 当供给不足时，公平程序、临时支持和追责能减少并处理损失，但不能凭空创造真人时间。
5. 人时报酬与实际可用劳动必须分开核算；不依靠税收、不没收积蓄与自由退出的组合，仍需后续发行和总量方案。

未采用“只给兜底余额便算完成保障”，也未采用“人人必须轮值”。没有设定机器必然无效或必须退出照护；机器能否满足具体需要须个别判断，不能用制造稀缺来维护真人职业。

## 四、独立对抗性审查

按作者要求，由 institution_review 与 boundary_review 分别独立提出反例。成稿前审查共同指出：方案方向可以成立，但必须写清真实短缺与退出后果，不能把机构担保写成永远有人愿意劳动。

| 审查发现 | 成稿中的处理 |
|---|---|
| 多人同时退出，发再多人时也无人可用 | 第五、六节：按具体能力核算容量、替补与跨区协作、明确未兑现需要；算术示例揭示余额与供给差别 |
| 交接一直等到有人来，形成无限留岗 | 第四节：事先限定最长交接，疾病和危险时即时停止相关劳动，替补责任由机构承担 |
| 退出要偿还全部培训和未来风险，变相强迫 | 第四节：不把缺编成本、拒绝劳动本身变成罚款，不扣已得报酬逼留岗；独立侵害另依法处理 |
| 免费排队被人为延长，诱导付费转单 | 第八节：公共私人时段区分、禁止出售队列、禁止同一服务双收费和利益冲突导流 |
| 所有心理支持被判为偏好，或指定某人被视为无限权利 | 第二、三节：按需要认定，必要心理照护免费；不保障无限时长或特定人的私人感情 |
| 家里有人就削减公共照护 | 第四节：不推定亲属持续可用，真实意愿、能力和期限需要确认，监护责任另作区分 |
| 服务者轮流拒绝某类居民，机构借自由拒绝卸责 | 第四节：个人不被强制履行，机构仍需安排并审查系统性排除 |
| 创伤安全、语言适配与连续性被当作付费升级 | 第三节：可作为免费方案条件，适配替代与特定个人支配权分开 |
| 长期非危急需要永远被插队 | 第六节：累计等待、专门容量、等待上限、主动升级和复评，不把排队当成交付 |
| 公共失约后只补发余额，无钱者仍得不到服务 | 第八节：优先实际接续，公共直接承接替代，无须个人先垫款；赔偿不得代替服务 |
| 既有司法文稿仍以余额支付必要照护 | 第十一节列出明确同步项；免费基本保障不能成为扣光个人余额的理由 |

成稿复查已完成。两位独立审查者均认为可作为研究提案，未发现阻断项，也不建议继续增加机构或条款。institution_review 确认免费保障、公共报酬、自愿退出与实际补救之间可以衔接；boundary_review 确认个人拒绝、机构反歧视、家庭支持和适配需要的边界已写清。两位均指出同一处定位笔误：“机器办事免费、人工跑腿收费”应指向主设定 6.7，已核对原文并修正。

主审另核对了三份关联文档的本地链接、容量示例算术和 Git 差异格式。独立审查是制度反例检查，未重新逐条核验所有外部链接；本次不宣称完成真实服务容量测量或现实法律合规认证。

## 五、完成与未完成的边界

已形成可供作者审阅的基本服务目录、申请流程、自愿专业岗位、接续与短缺规则、公共私人服务边界，以及旧设定同步清单。没有改写世界观主设定或将所有新增建议宣告为已确认正史。

尚未完成的是公共人时发行与长期总量闭合，以及真实人口结构、专业人数和服务时段的容量验证。本次调查和独立反例推演不替代这些工作，也不意味着需要先建立庞大财政模型才能写日常故事。
