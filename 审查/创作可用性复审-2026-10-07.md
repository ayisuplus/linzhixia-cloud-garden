# 创作可用性复审

日期：2026-10-07｜审查基线：`a082026`，主设定 v0.25、边界规则 v0.2 与索引指向的现行分卷。

## 一、结论

**未发现会推翻已确认世界底座或阻断普通地球日常创作的根本矛盾，可以开始创作。**这不等于每个旧分卷、情节候选和未决机制都能直接混用。确有一处已知收费文字冲突，以及若干在具体事件成为因果关键前需要定下结果的接口。

本轮不要求补齐底层医学、人格转接工程、完整法典或神界内部制度。审查关注同一个场景是否会得到互相冲突的结果；明确的虚构技术前提按作品事实接受。三路独立只读审查分别覆盖生命身份、治理与人时、空间与时间，主审核对原文后合并。没有把已知待定项包装成新发现，也不保证已经穷尽所有可能反例。

## 二、已通过的主要一致性检查

| 场景 | 按现行规则得到的结果 |
|---|---|
| 没有人时、拒绝工作或真人关系 | 仍获得充分免费身心服务、维护与续命 |
| 人工生命拒绝服务、离开领养家庭 | 不失去主体地位与基本保障 |
| 地球意识休息、拒绝或卸任 | 工具体系继续提供基本服务，不强迫它永久劳动 |
| 地球意识拥有最高日常管理权限 | 仍不能改法、侵犯人格主权、豁免能力界线或自审终审 |
| 换成机械、生物或数字载体 | 正常迁居延续本人，账户和有效责任继续，不产生备份与分支 |
| 睡眠、维修、原身蜕皮 | 不自动死亡，不要求完整人格备份，也不要求只用一块不可维修硬盘 |
| 新人工生命诞生 | 拥有自己的唯一人格，不等于复制旧主体；具体公共资格另定 |
| 自主数字终末 | 唯一人格不可逆销毁，不能临时发现存档复活，不连带其他生命 |
| 公众多数要求拥有某个人格 | 共同投票不取消意识主权，不提供数字奴役或人格复制许可 |
| 神界消息到达地球 | 遵守一至十光年对应的传播下限，不因中继或高能源而即时送达 |

强制迁居是否正当、人格平等与能力隔离是否值得保留，属于作品有意容纳的伦理争议，不作为逻辑错误消除。

## 三、在相关场景入稿前确定即可

### 1. 写具体人时报酬与欠款时

[主设定第二节](../世界观/世界观设定集-v0.25.md)仍将私人付款义务、最低报酬、公共发行来源列为未决；[人时卷](../文明与精神/文明与精神-卷十四-人时发行与流转-v0.1.md)明确是提案。不能前一场写“帮忙半小时系统自动新增半个人时”，后一场又把它当作私人必须从余额支付的债务。

写到时只需先确定该次属于无偿帮忙与赠谢、有效私人约定还是公共报酬，以及谁支付、何时成立。自愿相处和普通转账并不因此无法写；不要求现在把所有经济细则封板。

### 2. 写远方来信或调岗时

知夏十五至十六岁、阿姐同批略长，而具体出发、到岗、发信、收信尚未排表。若采用远方岗位，不能把当地当年的变化写成地球同年获知。正式采用时列出生、选拔、离地、到岗、发信、收信六项即可，不替作者设计事件。

[界线卷的旧季线候选](../文明与精神/文明与精神-卷十-界线登台与潮汐台-v0.1.md)仍有“回执到达意味着刚抵台”的旧解释，段首已明确不是校准后的现行剧情。应理解为地球此刻才知道其已抵达；不能直接复用为全知旁白。几个月后收到新声部本身不违规，两段消息可以在远方相隔几个月发出后都传播数年。现行迁移段落已经正确，旧剧情不改。

### 3. 写失能救援、找回记忆或重大损伤时

[边界规则第二至三节](../世界观/多形态生命-边界规则-v0.2.md)与[医疗卷](../文明与精神/文明与精神-卷八-医疗与健康-v0.1.md)保留紧急保全、事前授权和独立复核的具体程序。写某次不能回应的生命获救时，须明确可以立即保全什么、不能擅改什么。

记忆封存、主动遗忘和治疗的可逆范围仍待细化。须区分找回仍然存在但无法访问的内容，与补回已损毁的内容；不预设每种失忆都可恢复，也不得为了反转凭空补回已不可逆损毁的完整人格或借用已取消的备份。具体恢复能力必须在该事件中一致，不必因此设计整套记忆医学。

### 4. 写改法、政治投票或新生资格时

共同投票与地球受限管理的原则已定；参与范围、资格支持、截止时间和生效方式尚未定。不得因禁复制就认为制造大量独立新生命的公共资格问题已自动解决，也不能让远方主体在尚未收到议案时已经完成实时投票。这些只在政治事件使用前需要明确，不阻断城内普通生活。

## 四、明确的旧稿文字冲突及本轮处理

[交通卷](../世界观/物质基础-卷四-交通-v0.1.md)原第 64 行降临舱花人时，与第 82–86 行自动降临舱免费表相冲突；[天气卷](../世界观/物质基础-卷一-天气与自然环境-v0.2.md)也沿用出城一律花人时的旧概括。主设定此前已经识别，不能当作本轮新发现。

触发场景是零余额居民能否乘自动降临舱出城。本轮将互相矛盾的条目明确标为待统一的旧候选，不新增收费义务，也不擅自确认所有特殊旅行无限免费。正式写出城场景前仍须确定这一范围。城内基本交通、校园、家庭与普通修物不受影响。

另外直接同步两处已确认事实：机器保障卷的“根本规则权限另议”改为共同投票、程序另定；主体性卷明确正常迁居延续本人，回退仅为历史技术讨论，不允许完整人格快照恢复。这些是效力清理，不是新增世界规则。

## 五、使用边界与验证

日常可以开始写。只有当未决机制决定一个事件的结局时，再为该事件补充少量明确规则；不能把神界神秘、角色不知情或未展开工程当作任意改变结果的理由。普通故事不必等待所有参数齐全，旧季纲也不因审查通过自动获采纳。

独立审查者：`creation_identity_audit`、`creation_governance_audit`、`creation_space_audit`。三路均未发现新的根本矛盾，一致认为普通日常可写。审查覆盖上述现行材料；没有改动人物、单元、原审查报告或神界内部制度。

综合报告及六文件变更经独立审查者再次只读复核，通过；记忆恢复的表述已收紧为条件区分，不提前确认通用恢复能力，也未将收费、投票或迁移细则定案。
