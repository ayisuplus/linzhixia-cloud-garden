# 晨起图册经验

来源：2026-10-17晨起场次。当前版本始终从制作进度进入，以下是方法示例，不是永久道具规则。

- 发夹形状反复漂移：用作者实际指定的图为母版，不能只靠“小耳朵”等口头简称再造形状。
- 卧室变成另一个房间：空间母版管家具和出入口；角色姿势参考不接管整个房间。
- 汤圆三张表情一样：逐镜写清情绪目的和变化，表情是动作因果的一部分。
- 误删托盘：修改范围需明确到部件；去圆环不能推导成去承托盘。
- 图文错配：举盾完成图不能当翻身前图；杯子道具图不能证明知夏转头回避已在画面中。
- 智能家具只有声音：通过感知、等待、动作与状态切换让智能可见，不强制每个物件长脸。
- 被子显像像胶团：目标材质与实际生成形态分开记录，静帧不证明变形过程。
- 镜内保存人像易误读：注明保存预览与实时倒影的区别，人物不应同时出现在床上和柜前。
- 当前A010/011/014/015缺完整画面：可保留辅助参考与计划；缺口本身应有位置，不能被好看的旧全景填掉。
