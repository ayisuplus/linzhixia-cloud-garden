布局想法是：**北入、东坊、西居，中间一个可以被不同房间看见的小池庭；门外是一段真实有人通行的水巷。**

## 空间关系

- 门外沿水步道连续通过。收件台位于院墙退让出的凹位，不占步道；从外面取包后，经园门带进工坊。凹位背面与园内分开，不另开通往私宅的随意入口。无人机接近路径与避让仍待细化，本轮不宣称试飞通过。
- 北侧园门进入一个短前庭，照壁遮住池庭的一部分。向东绕过后到茶廊，先坐下说旧物的来历，再进入相邻修复工坊。
- 工坊靠东布置，材料柜与修复台在同一个空间。工坊西侧临池通廊，后续可细化窗、采光与看向池庭的视线，本轮墙体只是开口与体块占位。
- 东南端有独立的有顶试用廊，暂留4.5×3.5米净区，供走步、试鞋及其他物件试用；与池边、工具收纳分开，不作为专业舞室或完整舞蹈动作验证。
- 西侧通过可关闭内门进入生活区。起居、卫浴／洗衣、卧室的门均接有顶内廊，厨房／餐位接在南端；来客不必穿过这些房间。
- 池庭提供休息与跨院观看，植栽先作简单占位。东南角留一小块种植地和云生根系意象候选，未采用具体植物。
- 西侧院外有一座邻里小桥。水巷对岸是较高的邻居台地与房屋占位，提供层叠背景；桥和两岸步道仍在同一标高。对岸台地的具体入口不在本轮设计范围内。
- 公共画舫站暂建议放在水巷东端通向的街区节点，不挤在半园家门口；未建模、未定距离，不据此更改首集无人机配送。

## 为什么先保持家里同层

半园要支持搬旧物、工作、接待与长期生活。高低错落先由水面、云质承托边缘和邻里背景提供，卧室到卫浴、园门到工坊尽量不增加台阶。未来若需要阁楼或局部高台，再依生活与镜头需要增加。

## 暂定尺度与边界

| 项目 | 本次工作假设 |
|---|---|
| 院界 | 沿用旧草案约28×24米，672平方米；不是已批准的住宅规格 |
| 门外步道 | 约3米宽 |
| 水巷 | 约5米宽；只有本段占位，不确定全城河道标准 |
| 园门、室内、近岸步道 | 标高约±0；模型铺装薄层不代表真实门槛构造 |
| 水巷水面 | 约-0.45米 |
| 对岸背景台地 | 约+1.8米 |
| 试用留空 | 4.5×3.5米，位置与家具可调整 |

模型X向东、Y向北、Z向上；北向只为与旧草案对照，尚未锁定具体地理朝向和真实日照。云质承托用薄底板与圆润边缘代理，反重力不以新增巨型发动机外形定案；薄雾、水、云质的正式美术未制作。

## 已做的检查

- 本机Blender实际完成204对象的模型、四个相机与四张原始渲染，保存可编辑 `.blend`。
- 实际查看三维总览、揭顶、平面与水巷视角，调整了取景裁切和重叠地板；工坊工作台让出来客到达位置，收件凹位补背墙。
- 橙线表达来访／修复／试用关系，蓝线表达进入生活区；路线是空间讨论线，未做人物碰撞或动作模拟。
- 颜色只区分功能；没有修改角色、定款配色、世界观或旧平面／航线。仅保存本地空间讨论稿，未回填ToonFlow画布，不计作场景采用资产。
- 屋顶是简化体块；门窗、排水回路、构造、边缘防护细部、日照和无障碍尺寸尚未专项验证，不是施工图。
