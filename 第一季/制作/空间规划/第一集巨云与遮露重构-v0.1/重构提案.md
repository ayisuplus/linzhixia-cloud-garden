# 第一集：一朵巨云上的城市与穿云换景

> 2026-10-24作者纠正：城市应包在云里面，而非巨云底座上摆建筑。本提案中的底腹主导构图已被[云中园城设计](../第一集云中园城-v0.1/设计说明.md)替代，保留本稿记录推演过程。

2026-10-23｜设计提案，未建模、未渲染。作者本轮明确“整个城市在一座巨大的云上”；本稿据此重构城市承托与观看顺序。具体造型、分段时点、侧向全息小景为助手建议，尚未成为采用分镜。当前建筑语汇与资产沿用，旧工程保留。

**希望观众经历：从一扇窗看见一点线索，飞出局部才发现整座城市长在同一朵巨云上；随后借窗、云幕和高差，把这座城市一层层打开，最后落回具体人的生活。**

## 设定依据与本轮纠偏

- [城市卷v0.3](../../../../世界观/物质基础-卷三-城市与建筑-长洲云城-v0.3.md)第3节：云质下层稳定承托、上层可软；建筑与道路下局部加固。承载云质、普通水雾、全息虚景各有职责。
- 同卷第4—5节：多高度入口、云隙、水庭；墙、树、云带、高差共同组织显露。云像变化的园墙，也必须有晴朗开敞段。虚实包含倒影、帘影、声音、留白，并非每处都投影。
- [学院方向](../../../../世界观/学院-水墨外观与虚实课堂-设计提案-v0.1.md)：整个学院外景属于水墨环境，不是只有建筑黑白。学院边界与交通技术未定；连续飞行穿过雾的画面不意味着传送。
- [学院空间与航线](../../../../世界观/山水书院-空间布局与首集航线-v0.1.md)提供生活空间→水庭→墨雾方向→长洲→作坊的叙事关系；其旧2:20预算已由作者后续58秒决定取代。

旧建模把园城先拆成几块完整椭圆平台，再给各自配云，继而在下方补一层云海。这改善了表面，却仍把“园岛”当城市单位。本轮应改为：**同一巨云本体是整体，院落与街巷是其上生长的生活面，云谷是整体内部的凹入与留空。**

## 一、先重构巨云，再安放既有建筑

1. **共同外轮廓与底腹。** 巨云有能被读成一个整体的外缘、起伏云肩和垂卷底腹。各区下方由宽窄变化的云脊连通，不靠细桥暗示连接。内部可有云隙、天井与气流通道，但不能让每个生活区都变成一座完整可数的独立岛。可拆成多个建模对象，构图与空间关系必须连贯。
   远景城区也归入这朵巨云的后肩；上一轮五组远景各配一团底座的表达应取消，不再把远景做成新的小云岛。
2. **生活面不再各带一个圆盘边界。** 保留房屋和院落内部布局；外部承托改为顺云势延伸的台地、园径、水庭与相邻高差。局部石铺地、木台、泥土花圃可以保留，但不是每组建筑都围一圈完整草地托盘。需要移动时按建筑组团整体调整，不改变已认可的单体设计。
3. **巨云本体与环境云海有区别。** 环境云海更低、更疏，并在巨云外缘留出一段空气间隙，让观众看见本体的侧面和底缘。不能让无限平雾吞掉本体轮廓，否则又只剩“房屋漂在白地上”。巨大来自城与云的比例，不等于做成厚重土石大陆；具体尺寸先用约1.85公里原航线作参照，经构图验证后决定，不写成新的世界观定值。
4. **一次有明确尺度的侧向展开。** 从云肩旁沿前进方向掠过：近处云壁快移、中景桥与屋顶较慢、远处同一云体继续托着城区。画面同时出现生活面、侧面下卷的云腹和更低的环境云层，才说明城市依托一朵巨云。无需绕城一圈、停机展示全地图或突然回头。

## 二、云与窗分别负责什么

| 元素 | 空间职责 | 无人机经过时观众经历什么 |
|---|---|---|
| 承载巨云 | 稳定承托、组织高差与整城轮廓 | 看见城市长在云上；不把承重云质随便当烟钻穿 |
| 云谷中的普通薄雾 | 局部遮挡与分隔 | 飞入预设开放通路，遮住部分景物，露出新的前后层次 |
| 实体窗洞、廊口 | 限制视域、给出明确目标 | 远处只见一亭或一段桥，穿过后才知它与整座园城的关系 |
| 倒影、帘影、声音 | 让尚未完整显露的实景先留下痕迹 | 先有倒影/水声/树影，再见真实空间；不必都加全息 |
| 侧向借景窗（可选一处） | 体现未来技术扩展古典园林 | 近旁真实窗框、植物不变，窗内局部远山是明确记录的仿真景，侧移时显出其与真实小院的叠合 |

三次穿窗仍可保留，但各自有不同揭示结果。不能把圆孔当穿越机竞速门，连续重复“对圆心—钻孔—继续飞”。先决定窗内要给的线索、窗外要延迟显露的空间，再确定孔口、云幕与航线的位置。

**一处完整的换景示例：**从廊下远望，圆窗只框住一座水榭，云后去向不明；前行时水声逐渐清楚。穿过窗洞后薄雾从画面一侧掠走，水榭下方的长廊、下层水庭、再远处依托同一巨云的城区依次露出。水榭始终是同一个空间锚点，观众重新理解它的尺度与位置，不是无缘由换了一套背景。

## 三、58秒观看顺序建议

以下是预算，不是已经完成的时间线；原A/B/C穿窗约10.29/20.54/42.63秒，可作为重排起点。保留起终点、送件因果、三次穿窗及末段贴水，不强守旧航点。路径变动需重新检查净空和速度。

| 时间预算 | 画面与动作 | 这段负责让观众理解什么 |
|---|---|---|
| 0—10秒 | 从学院外廊起飞，檐、墙、树遮住大全景；A窗先框住一处水榭/云肩线索，再从真实开口穿出 | 从生活的小尺度出发；学院天空、植物、雾均遵守水墨方向 |
| 10—20秒 | 沿巨云外肩顺势掠行，雾边退开，云的侧面底缘与其上的连片城区一同展开，留数秒清楚观看 | 第一次明确“整城由这一朵巨云承托”；学院到长洲仅作为边界表现候选，不新设传送机制 |
| 20—32秒 | B窗先给一处上层亭/桥的局部；真实洞口后进入云谷开放航道，经短薄云幕，下层水庭与桥下街巷展开 | 同一处空间从一个层面展开为多个层面；第一次主要的穿云揭示 |
| 32—43秒 | 视线沿水脉转向生活区，侧向窗、树影与倒影给出借景；C窗把水巷方向框住，穿后空间再次打开 | 收回到可居住的园城；可选全息仿真仅在旁侧借景窗中，不占据真实通行孔 |
| 43—53秒 | 前方雾薄、视线开阔，贴水飞过；岸上建筑与水中倒影同时掠过，过桥前平顺抬升 | 用真实水、倒影和前后视差完成虚实；保持高速但方向明确 |
| 53—58秒 | 收件台、廊柱与庭院替代大全景，放缓收稳到原终点 | 大城市落回送一件东西的日常，不额外拖长风光展示 |

全程用“局部线索→短遮挡→完整展开→留出观看时间”构成节奏。不要全程浓雾，也不要每穿一扇窗都来一次白屏。穿雾前能预判出口方向，遮挡时保持部分连续轮廓或明确方向；雾幕之后不要立刻急转。速度来自空间掠过，画面变化优先来自真实遮挡与高差，不能靠摄影机频繁左右寻找风景。

两批仍按0—30秒、28—58秒保留2秒重叠。建议28—30秒放在一次揭示之后，让同一桥、水庭和远景地标可见，便于生成连续性检查；不把重叠区放进纯白云中掩盖空间关系。只属执行布局建议，未提交生成任务。

## 四、虚实结合的具体界线

主线先用近实远虚、云中藏露、窗内外视域差异、实物与倒影完成，不靠新增技术说明。若保留一笔全息借景，选择本地仿真远山，创作记录明确为仿真；不默认异地无延迟直播。无人机从旁侧实际通道经过，镜头能同时看见真实窗框/院内植物与借入的远景。不用闪白、故障扫描线或界面字幕解释，也不能从一幅影像里瞬间抵达别处。

学院离校段的水墨→有色转变必须连贯，具体边界技术仍未定；本稿只规定观看顺序，不把过云表现写成技术定案。后续可见性测试应同时检查人物/环境采用色彩，不把整城改成水墨或把学院只做成灰瓦房。

## 五、重建与验收次序

1. 隐藏当前各独立托盘的显示，以保留的建筑组团为参照，先做单一巨云本体、生活面与云谷。旧工程与原承托网格留历史副本，不在未验证时直接删除或把结构当雾。
2. 先用斜侧总景证明巨云的共同外轮廓与尺度，再用航线机位证明能在58秒内自然看到它。若必须大幅绕路或回头才能看清，重排空间和机位。
3. 为三窗分别确定“窗中线索、遮挡物、揭示目标、持续可见锚点”。先在低模中做出遮露，再加雾；云不能替代缺失的实体布局。
4. 先渲染巨云侧面＋第一次穿云前/中/后的同路序列，检查入口可预判、出口不同层次展开、无突然撞墙感。静帧不验证运动节奏，必要序列必须连续观看。
5. 这些成立后再录完整58秒，检查三窗、贴水、云的时间稳定性与两批共享段。人物活动、最终云纹理与生成模型渲染在后续对应阶段处理。

本轮只完成原设定回查与重构提案，不改写主世界观、不替换采用资产、不启动渲染、不宣称新航线成立。下一步施工对象已经明确：巨云本体与生活面的关系优先，接着验证第一次窗—云—城的揭示。

独立概念审查已完成，重点核对整城共同承托、远景归属、三窗的不同职责及学院全环境水墨边界。审查支持上述重构方向，不代表具体构图、飞行或仿真技术已经验证。
