# 半园与门外水巷 · 空间调整 v0.3

2026-10-14｜布局候选，待作者讨论。承接作者授权：调整草模，完成水巷望园门、进门见池庭、工坊望院外三个固定视角。本轮只推进空间，未制作正式场景美术。

## 本轮改变

- 保留约28×24米院界、北入东坊西居和家庭同层。茶廊由约11×5米缩至6.6×4.3米，东侧腾出植栽缓冲。
- 入门仍有照壁，照壁东南增加树池和低座墙。客人绕到东侧之后，逐渐看到池庭；私人路线向西进入内门。
- 临池通廊增加一个向池边伸出的停留处；它和入口树池组织前、中景，不用浓雾遮盖空间问题。
- 工坊西墙改为宽窗与独立通行门。工作台位置微调，窗看池庭，门侧可见园门附近的水巷片段；不是整个水巷都能看见。
- 北墙加真实墙洞，门外步道连续通过，收件仍在退让凹位。对岸房屋错开，增加沿岸种植。公共画舫站仍在本轮范围外。
- 橙、蓝、绿分别显示来访／试用、回家、路人通行。匿名尺度人偶与台上旧物均为占位，不是人物或舞鞋正式设计。

## 判断与下一步

本轮优先让工作台、庭院和门外生活有可见的联系，推荐第三个视角进入下一轮美术探索。第二个视角适合检查池庭尺度和廊柱的疏密；第一张可继续推敲园门的辨识度。院界暂未缩小，整体仍有收紧余地。

云质与反重力继续沿用世界观；本轮边缘云体仍是体块代理，未加全息、雾效或新设备定案。色彩只是空间区分，没有改动角色或已采用服装配色。
