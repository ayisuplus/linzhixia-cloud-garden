## 结论与适用范围

针对当前“Codex 策划／生图，云端生成视频”的制作方式，rhTV 无限画布与 Toonflow 的文案、参考素材和生成结果编排职责高度重合。建议优先验证 rhTV 作为主画布，Toonflow 保留为可选本地工作台，减少两边复制提示词与回填视频。

两边画布不能保证同样的生成质量；效果还取决于实际模型、参数、参考方式与输入素材。Toonflow 的直接 MCP 操作便于批量编排；本轮 rhTV 只能确认浏览器入口与官方产品能力，尚未确认可用的公开画布管理接口。

## 本轮证据

- 官网页面检索结果在本轮出现截止 10 月 10 日的活动宣传。宣传不等于作者账户已经具备权益，更不能当作今后常态成本。

## API 核对

| 能力 | 已查到的公开文档 | 与 rhTV 画布的关系 |
|---|---|---|
| 模型、AI 应用、工作流、LLM 调用 | 官方 API 总览列出四类服务 | 可提交生成任务，不能据此认为 rhTV 页面创建了节点 |
| 上传图片、音频、视频等 | `POST /openapi/v2/media/upload/binary` | 为模型／工作流提供输入；不证明资产已加入 rhTV 项目 |
| 获取 ComfyUI 工作流 JSON | `POST /api/openapi/getJsonApiFormat` | 返回生成工作流图，与 rhTV 创作画布的布局、项目与版本是不同对象 |
| rhTV 项目、节点、连线的创建／修改／保存 | 本轮未查到明确的公开接口文档 | 不声称绝对不存在；目前按网页操作规划，不依赖未确认接口 |

官方当前 Key 规则：消费级会员 Key 可调用 AI 应用／工作流 API；标准模型 API 与 LLM API 的直接调用要求企业级共享 Key。网页活动优惠、会员免费时段和 API 计费不能视为自动通用，具体以账户权益及目标入口结算为准。

上传 API 返回的外链有效期为一天；该接口不是长期图床或文件归档服务。它的临时链接不作为 Eagle 正式资产引用，也不据此推断 rhTV 项目资产的保留期限。

## 建议采用的制作链

1. Codex：世界观、剧本、分镜、镜头提示词，以及图片生成与修改。
2. rhTV 网页：上传本轮采用素材、编排镜头、连接生成节点、利用实际可用的账户权益生成视频、比较候选版本。
3. 下载结果：一并保留输入参考图、完整提示词，记录镜头编号、素材版本、实际模型／参数、任务标识和采用原因；rhTV 画布能否完整导出尚待核验。
4. Eagle：保存正式素材与采用结果；剧情和制作记录继续留在本项目。

Toonflow 如后续需要编排本地 ComfyUI 或直接 MCP 批量操作，仍可启用。当前没有卸载、删除节点或清除历史文件。

## 切换前的最小验证

- 在内置浏览器登录作者原账号，核对已有项目及目标视频入口的实际权益。
- 用一份已采用的本地图片与一条镜头提示词检查上传、引用、节点关系及保存，重开后确认可恢复。
- 在作者已允许的参数与额度内试一个短镜头，确认实际结算入口、生成结果和下载；本轮未执行。
- 把结果与来源归档到 Eagle，确认可定位后再将制作进度的默认工作台改为 rhTV。
