# 林知夏制作入口

项目根目录：`E:/projects/内容创作/未来女孩林知夏`。先读该目录的 `制作进度.md`、`创作速查卡.md`，再读本次已确认的剧情与采用素材。目录不存在时说明缺项，不套用其他项目。最新作者决定优先于历史稿和外部模板。

当前工作台是 Toonflow；Codex 创作、生图后导入。作者在云端用 MiniMax H3 生成视频并下载回填。技能安装或提示词定稿不授权媒体生成，不自动提交云端任务。只处理本次要求的阶段。

## 按阶段读取

| 阶段 | 方法与输出 |
|---|---|
| 资产 | 先确定本批需求和实际用途，再列角色、场景、道具及必要状态。用下方资产模板；真实参考存在时可用已安装 character-turnaround、outfit-breakdown 等技能，新角色从设计提案开始，不把参考提取当作原创设计。场景先验证通路、高差和动作空间；空间母版不是已建成的三维模型。 |
| 分镜脚本 | 读取项目 `.claude/skills/storyboard/SKILL.md` 与其场次卡、镜头卡模板。需要调度或运镜方法时读取已安装 `cinematic-director` 的 D 模式；项目设定与本次任务范围优先。 |
| 关键帧 | 读取 [交付模板](references/deliverables.md)，按镜头需要选择首帧、尾帧或中间动作关键状态。可参考导演技能 E 模式，采用的 2D 风格优先于写实摄影示例。 |
| 故事版 | 将采用关键帧、镜头说明、声音和预计时长按顺序编排。缺图明确标缺，不整页重新生成而改变已采用人物和构图。静态故事版不等于已经测时的 animatic。 |
| 视频交接 | 按模板在 Toonflow 放完整提示词、实际参考与回填位置；以当批云端入口核对 H3 版本、时长、参考槽位。未核实的参数标待核，不从其他模型模板推定 H3 能力。 |

正式顺序：资产 → 分镜脚本 → 关键帧 → 故事版 → 视频。资产前需要当前剧情或设计需求，不能无依据生产整季素材。分镜阶段可用低成本构图草图验证空间；这是草稿，不改变正式阶段顺序。

## 关系与连续性

- 资产固定身份、空间、道具结构；镜头描述一段时间里的视听行动；关键帧固定某个瞬间；故事版呈现镜头之间的关系。
- 一个镜头可有多格说明动作，但不要求每格单独生成高清关键帧；长镜头可以承载连续动作，不机械切成每个动词一镜。
- 同一场内继承人物位置、运动方向、道具破损与持有关系；允许有意跳时、反打和转场，写明理由。世界坐标关系与屏幕左右分开。
- 多视图资产板只传递身份、结构；生成视频不能把网格、多个视角或板上文字一起演出来。
- 镜头卡可以引用公共字段；提交到云端的每份提示词必须展开成独立可用全文，不能留“同上”。
- 穿越机感、一镜到底、希区柯克变焦先写路径、目的、主体调度和结束状态；需要时用空间草图/微缩模型验证。借镜头方法，不自动借悬疑或沉重气氛。
- 以希望、青春、轻松诙谐为基调；首集校园旧舞鞋方向以最新稿为准，怀表旧稿、冷开场及旧 17:30 分场预算不能充当新首集。

## 保存与完成判断

使用现有稳定编号；已有 ID 不改名重编号。区分待设计、待生成、候选、待审阅、已采用。采用项记录版本和真实文件，不把占位路径或写好的提示词报告成已生成资产。

Toonflow 操作通过其实际 MCP 工具和节点函数完成：先发现当前项目、画布及 schema，不直接改画布 JSON；工具未接通可先交文字并标未入画布。沿用 toonflow 技能的工具操作方法，不引入应用内 workflow 的强制 Seedance 路由。正式素材按现有 Eagle 约定归档。

交付说明本轮完成的具体阶段、真实文件、尚缺输入和未验证部分。模板字段按需要填写，不强迫简单镜头填满整套表格。
