# 四类交付模板

编号沿用项目既有规则；以下方括号是待填项，不是已经存在的文件。

## 资产条目与提示词

资产 ID / 版本 / 类型 / 当前状态：
依据：已确认剧情段落或设计需求；未确认设计另标提案。
用途：被哪些场次、镜头使用；要消除什么识别或空间问题。
保持项：身份轮廓、服饰配色、场景锚点或道具结构。
变化项：本次允许改变的状态；其他部分沿用哪一采用版本。
参考：真实路径或 Eagle ID + 版本 + 各自职责；缺失写“缺失”。
提示词：采用画风 + 对象可见特征 + 结构关系 + 展示视角 + 光色 + 针对性约束。
验收：同人、结构一致、身体/物件完整、空间走得通、状态明确；候选不自动采用。

角色视图版式服从实际用途与采用模板；舞鞋需要交代同一双鞋的左右关系、损坏位置及修复前后状态，但不得自行决定损坏原因或传承人物。浮空园院需交代园院连接、高差、步道及水流方向，不从一张美图宣称已验证全部隐藏结构。

## 关键帧卡

- 所属场次 / 镜头 ID / 帧 ID / 版本 / 作用：首帧、尾帧、动作状态或转场连接。
- 时间点与可见瞬间：姿态、接触点、视线、道具状态。
- 参考绑定：每份真实参考负责身份、服装、空间、结构、风格中的哪项。
- 构图：主体位置、可见身体范围、遮挡、前中后层、观察方向。
- 相机：高度和透视关系；焦段只在有意义时作设计目标，不声称模型物理精确。
- 光色：世界中的光源与本机位看到的受光关系；沿用采用 2D 风格。
- 独立图像提示词全文：描述一个瞬间；运动路径写在镜头卡，不塞进静态姿态。
- 与邻帧关系：继承哪些事实、改变哪些状态；运镜可改变机位与构图。
- 输出真实文件 / 审阅结论 / 采用状态：未生成写未生成。

首尾帧固定同一主体身份和场景结构；只有锁机位镜头才要求相同相机。希区柯克变焦可改变焦段与相机距离，检查主体画幅占比和背景透视变化。不存在首尾槽位时，尾帧可作为审核目标，不假定能上传。
