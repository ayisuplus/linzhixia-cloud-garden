## 一、固定骨架与本稿选择

| 层级 | 内容 |
|---|---|
| 沿用 | 知夏 15–16 岁、学徒；师傅远行，她临时照看半园；常驻只有知夏与汤圆 |
| 沿用 | 残冬，一位总在黄昏出门的暮年老人，一只停摆旧怀表；第一次独自接活的紧张 |
| 沿用 | 第一次独自送汤圆年检：平潮、询问降噪、知夏拒绝但还说不清缘由 |
| 沿用 | 师傅仅留言与笔记；单元末阿姐来信，不写实时问答，不提前出现审查空白 |
| 本稿提案 | 第三人称限知，贴近知夏；约三天内完成简单委托；样章暂以 6,000—8,000 字试写 |
| 本稿提案 | 老人暂称许伯，等的是一位约好来访的老友；不是等知夏救赎，也不引入恋爱或终老倒计时 |
| 尚不锁定 | 绝对年份、生日、老友姓名、怀表制造年份；不会为这一单元私自规定星际速度或人时发行 |

单元中的“她第一次”限于知夏第一次独立承担，不声称以前从未有人这样关心物主或机器。

## 二、故事要发生什么

知夏希望师傅回来时，发现她已经能像个修复师那样接待客人。许伯带来一只停摆怀表，说“想让它像以前一样”。她先把“以前”理解成完好如新，准备了一份漂亮的效果预览。许伯看过却说，表不是这个样子的。

她没有已经毁坏怀表，也没有被机器技术难住。真正的失误是急着证明自己能修，却没问清楚客人想保留什么。她重新约定范围，在机器支持下完成一项符合学徒能力的修复，把仍带使用痕迹、重新走动的表交回。

她最后看见许伯等到了老友。两个人没有谈什么重大往事，只挪出一个座位、问一句路上冷不冷。她第一次明白：自己完成的可以只是一件具体的小事。

## 三、怀表与委托人

### 怀表卡【本稿提案】

- 来源：许伯年轻时的一件常用旧物，已经陪他几十年；具体制作年份和转手史暂不写。
- 外观：磨亮的表冠、表盖上的一道浅划痕、柔软旧表袋。三者只选一处作为反复出现的细节，避免堆满象征。
- 功能：原本可走时，近期停摆。虚构故障限定为设备能够诊断、且在学徒现有训练范围内可处理的问题；正文不编未经核对的钟表技术步骤。
- 可行性：机器既能修复原件，也能提供功能与外观方案；不只会换新。不存在“机器无法保留痕迹”的障碍。
- 物主最终选择：恢复走时，保留长期使用的外观，完成必要清洁；不要求故意保留会继续损坏机构的故障。
- 道具不是灵魂容器，不自动读取或播放许伯的回忆。旧物历史来自他愿意说出的部分。

### 许伯卡【本稿提案】

- 暮年外貌；是否继续蜕皮不是本单元议题，不暗示付不起续命。
- 每到黄昏出去走一段路，习惯在廊下坐坐。知夏觉得他“像在等谁”，不替他诊断孤独。
- 老友过去常与他散步，后来搬到别处；这次约好来访。他想让怀表重新走起来，赴这次普通的见面。
- 选择半园的原因：喜欢边坐边看人做事；知道师傅远行、知夏是学徒，仍愿意让她在能力范围内试这件简单活。机器免费修复一直可选。
- 他可以改变主意、带表离开，也可以选择保留痕迹；不会因为配合主角成长就失去自己的判断。
- 保留一点日常脾气：不急着讲来历，夸预览“很漂亮”却迟迟不点头；最后由知夏追问清楚，而非靠猜心成功。

## 四、这一单元的最小约定【局部提案】

这些是许伯与知夏本次商量的做法，不直接代表司法法条或行业统一规范。

1. **先检查，再决定是否修。** 许伯同意非破坏检查；开工前看清方案和范围。
2. **坦白学徒身份。** 超出训练范围就停止手工作业，交由机器完成或另行商议，不靠逞强拖住物件。
3. **选择权在物主。** 知夏可介绍恢复、保留或替换方案，不能替许伯决定划痕应当有意义。
4. **本次不预先约定报酬。** 知夏愿意将简单委托作为练习；许伯可以事后赠谢，也可以不赠谢。不是“所有学徒劳动都免费”的社会规则。
5. **物与故事分开。** 允许修表不等于允许公开来历；知夏听到的私人话不写进公开招牌或展示故事。
6. **检查结果与心意分开。** 设备记录可以帮助核对物件与过程，不根据计时自动解释许伯欠多少人时。

结尾可采用一笔自愿赠谢，具体数额不写。知夏不把它当成机器给自己的“合格分”，也不以赠谢高低证明许伯的情感深浅。本单元先展示清楚约定后的相处，拒付和模糊承诺留给后续真正需要它的故事。

## 五、七个场景

| 场景 | 实际行动 | 知夏的变化与信息量 |
|---|---|---|
| 1．开门 | 她按师傅笔记摆工具，又把招牌扶正；机器早餐已经送到，汤圆指出她把同一张桌子擦了三遍 | 免费日常只用动作交代；她怕不像个真正的修复师 |
| 2．第一位客人 | 许伯带停摆怀表来；她说明师傅不在、自己能做哪些检查。双方同意先检查再商量 | 她急于接住第一次机会；“像以前一样”尚未问清 |
| 3．过早准备的预览 | 设备给出可行方案，她先挑了外观整新的预览。许伯说“很漂亮”，把手却放回旧表袋旁 | 他没有认可；她意识到礼貌不等于同意。原件尚未动过 |
| 4．重新问 | 她承认自己理解错了，问过去究竟是什么样子。许伯指着表盖，说明想要恢复的功能和不想抹去的使用痕迹 | 她开始把愿望问具体，确定操作范围；不把全段往事逼问出来 |
| 5．小修复 | 检测、照明和工具辅助一直在；她做训练范围内的清洁与简单处理。练习件先试，原件缓慢完成，再用设备检查 | 手艺仍青涩；汤圆可靠，不用失误毁物制造险情。学会按约定收手 |
| 6．年检 | 等最终观察完成的时段，她独自带汤圆去年检。读数平潮，对方问是否降噪，她把汤圆拢近一些，说不用 | 不出现微跳或危险警报；她暂不能把理由说成完整哲学。检测员身份不用于裁定整个机器司法分工 |
| 7．交还与来信 | 她亲手交表，许伯确认结果，随后到廊下赴约。晚些她在半园读到阿姐积压抵达的一封日常信 | 完成承诺而不包办他的人生；被选择的时间与远方家人形成轻微呼应 |

第三至第五场可以跨两天，避免几句话跳过实际劳动；第六场与待交物观察并行，并非拖延交件。具体天数在样章节奏中微调。

## 六、三种声音：只作试写，不锁口癖

**知夏，想显得稳当却先说太多：**

> “师傅出门了。不过我可以先看看——只是看看。要动哪儿，我会先告诉您。”

**汤圆，纠正具体的事：**

> “你已经把这张桌子擦了三遍。”
>
> “第四遍不计入清洁效果。”

**许伯，客气但没有交出判断：**

> “是很漂亮。”
>
> 他把预览放下，摸了摸旧表袋。
>
> “不过，我拿来的那只，不是这个样子。”

这句不表示许伯认不出自己的表，而是他不认可外观目标。知夏的下一句应是询问，不是替他总结人生。

年检对话沿用“平潮”“要不要顺手降个噪”“不用了”，不让检测员突然讲出后续秘密。阿姐的信先用生活细节与共同童年建立亲属感，暂不写坐标、转岗或屏蔽痕迹。

### 消息表：发送和收到不混写

| 信息 | 发送／发生 | 知夏何时收到或知道 |
|---|---|---|
| 师傅留言 | 远行前或之后某时 | 开篇可以读已保存内容，不推定实时在线 |
| 阿姐第一封信 | 比抵达早，航程和传播时差未定 | 单元末抵达；知夏可以回信，但不安排当场收到回复 |
| 第七单元抵台回执 | 机器早先抵达后发出 | 第七单元才到人间；不能据此断言此刻刚抵达 |
| 第十二单元新声部 | 必须在相应机器抵达并参与之后形成 | 第十二单元听见；与回执的传播及放行规则仍须统一 |

后两行是给作者的约束，不进入第一单元叙述，也不算完整通信时间表已经解决。

## 八、样章验收边界

- 机器能充分服务，许伯仍有选择知夏的理由；知夏被选择不靠机器失职。
- 怀表仍是原件，修复有动作、有物主同意；不拿许伯的沉默当同意。
- 知夏确实犯了理解上的错，但只完成学徒可做的小事；第十一单元的较难修复仍有成长空间。
- 老人的见面由他和老友安排，知夏不负责填补其全部人生；暮年不暗示续命经济压力。
- 不靠不可逆破坏或人为技术限制强造“两难”；此处的难处是理解别人、承认误判及尊重选择。
- 汤圆可靠又有性格，平潮、不微跳；知夏拒绝可选降噪尚不等于已经理解全部制度。
- 无恋爱线、无五位台主／流放／合唱揭秘、无阿姐即时跨星海对话。
- 新情节与具体声音仍为本稿提案；正文写成后再检验，而不是因为清单齐全就宣告作品成立。

下一份成果应是依据本稿写出的小说样章。全季日期、人时完整法则及后续真相不在本稿中假装解决。
