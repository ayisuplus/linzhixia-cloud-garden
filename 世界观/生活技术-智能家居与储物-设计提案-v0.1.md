# 生活技术：智能家居、全息窗与储物手镯

2026-10-15｜**设计提案，不自动替代主设定。** 来源为作者关于全息窗、储物手镯、一键穿戴、会说话的床及可定制房间场景的连续讨论。本轮授权展开创意与起居室概念设计。

## 作者提出的方向

- 窗可显示想看的地方，像普遍分布的远程摄像视点；全息投影进一步让人定制整个房间场景。
- 有传统衣柜，也有“储物手镯”；衣服可以随身收存，也能留在柜中展示。希望支持衣服逐渐展开成形的一键穿戴。
- 家具可以智能化，包括能开口说话的床。作坊不强求明显科技外观，外景与起居室承担主要未来感。

## 本轮家具方案（待采用）

| 家具／设施 | 做什么 | 可以拍到的生活动作 |
|---|---|---|
| 全息借景窗 | 庭院实景、异地影像、记录或仿真之间切换 | 说“今晚看海”，一侧窗景变为海面，真实庭院仍在另一侧 |
| 场景投影系统 | 墙顶影像、光线、声音共同营造场景；环境风感另由实际设施提供 | 阅读时变成安静竹影；星海模式下墙顶展开少量星图；收起后回到原本房间 |
| 云质坐榻 | 用可调支撑与软硬变化服务坐、躺、靠，不凭空增加材料 | 靠背慢慢放低、脚托伸出，原位置仍能看见庭院 |
| 会说话的床 | 可选语音回应，配合姿态支撑、温度和唤醒方式；留待卧室设计 | “再躺五分钟。”床回答“好，五分钟后我把窗边的光调亮。” |
| 智能茶几与送茶托 | 茶几局部调节高度；小托盘靠反重力稳定移动，杯子仍放在实体托盘上 | 人窝在坐榻里，茶托慢慢靠近；收回时让出膝前空间 |
| 可展开的阅读／通信界面 | 需要时出现，内容与场景投影共享房间界面 | 茶几旁展开一页内容，结束后视线重新落到院子里 |
| 展示柜与储物镯托座 | 实物展示与便捷取用并存；托座提供存放位置，暂不定义供能方式 | 常穿衣物留在镯内，喜欢的织物、书和陶器留在柜里 |
| 光声环境设施 | 灯光、帘幕与声音按选定模式协调，降低不需要的提示 | 一句“安静一会儿”，家具停止插话，保留庭院水声 |

语音回应可以集中在一个家居系统，也可由具体家具就近发声；建议默认避免多件家具同时说话。是否赋予独立人格尚未设计，会说话不自动等于有自我。若后续设为有自我人工生命，沿用现有主体规则，不能继续当作任意改写的工具。

## 起居室的四种状态

1. **日常／会客**：真实庭院为主，坐榻正常坐姿，茶几可供两人使用，投影收起。
2. **阅读／学习**：局部内容界面与照明展开，座椅提供支撑；仍保留走向庭院的通路。
3. **夜海／观星**：全息窗显示海天，墙顶投射少量星光与水影，真实庭院留作空间参照。本轮概念图选择这一状态。
4. **休息／安静**：坐榻放低，减少提示，声光变柔；床的完整睡眠方案留到卧室设计。

全息影像负责视觉，实体家具负责支撑；不把投影当作可坐、可踩或可喝的实物。改变景象不改变房间的实际出口。

## 尚未确定的世界观问题

- **全息窗的来源与边界**：助手建议区分公共／受邀视点、记录影像与仿真，远方内容沿用传输时延。这是兼容现有世界观的建议，不将作者“想看任何地方”擅改成已接受的详细权限方案。
- **储物手镯**：作者提出极大容量与一键穿戴；空间机制、容量／重量、物件与生命的范围、原件如何保存都未定。助手此前建议只在身边存取、不能远程跨镯传递，以兼容无传送门方向，**尚未获作者逐项确认**。
- **穿戴表现**：建议适配衣料连续展开、贴合，旧衣原件也能保留；是否所有衣物都支持、如何处理旧舞鞋与修复痕迹，需要后续讨论。
- 本轮图中的镯子只是外形占位，不修改知夏现有采用造型中的玉镯身份或赋予其已确认功能。
- 家具的云质变化、反重力茶托与设备能耗均为拟议用途；不宣称现实科学已验证，也不新增无限材料复制或任意传送能力。
