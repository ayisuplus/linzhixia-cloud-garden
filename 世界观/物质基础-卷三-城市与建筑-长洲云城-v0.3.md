# 《未来女孩林知夏》物质基础设定

## 卷三：城市与建筑 · 长洲云城 v0.3

日期：2026-10-14｜状态：本轮讨论已获作者授权纳入世界观。主设定仍为[世界观设定集 v0.26](世界观设定集-v0.26.md)，本卷展开其第九节。取代[城市卷 v0.2](物质基础-卷三-城市与建筑-长洲姑苏城-v0.2.md)的现行城市描述；旧卷保留历史。

**本卷区分三层：**“已纳入”是作者提出或认可的世界方向；“设计原则”是本轮讨论形成的落实方法；明确标为“候选／待设计”的名称、技术方案、生态性状与镜头例子用于继续创作，不等于具体物种、施工方案或首集事件已经定案。

> 长洲是一座生长在特殊云质材料上、能够缓慢迁行的未来园林城市。人们带着家、邻居和珍惜的生活走向远方；熟悉的小院留在身边，窗外的天地不断变化。

## 一、已纳入的城市核心

1. **新中式、写实治愈、充满希望。** 中国园居与江南文化构成美学主轴，真实可信的材质、光影、动作和日常使用支撑写实感。旧“日系治愈3D CG”不再作为全片总风格。
2. **云质材料与反重力技术配合。** 无需以土地或厚重土石浮岛作为全城必备承载基础；云质轻盈、轻薄、流动性强，能随能量调控改变软硬而自身质量基本不变，负责结构承载与植物生长环境；反重力系统负责整城悬浮。
3. **立体园城。** 取重庆式高低错落、层层叠叠、多高度地面的空间启发，与园林的院落、回廊、水巷、桥和借景结合，不以明显的一二三四五环组织长洲。
4. **云中园居。** 城市有云中仙宫般的意境，同时承载真实居住、上学、修复、交通和邻里生活；云雾参与遮挡、分隔与移步换景。
5. **虚实结合。** 全息仿真可以与真实园林空间共同造景，拓展借景、映景与远方联系。
6. **工程成为风景。** 雨水收集、排水、水循环等设施可以表现为浅渠、溪流、池塘、叠水与瀑布，并参与城市空间组织。
7. **筋斗云与云上画舫。** 个人按需出行采用筋斗云意象，公共交通采用云上小舟／中国古船与画舫意象；外观、尺寸与线路继续设计。
8. **云生植物与土植并存。** 存在直接生长在云质中的植物，穿行云间可以遇见奇异生态；居民也可保留泥土、挖土种植，材料进步不取消个人偏好。
9. **整城可缓慢迁行。** 长洲能够漂动、飘走，带着完整日常生活移动；江南是文化根脉，太湖—运河是故乡地理参照，不再限定所有时刻都在旧苏州正上方。

## 二、科技、文化与治愈的关系

技术让人有条件从容生活，也支持快捷、远行与更新。新中式通过空间关系、器物使用、四季感受与相处方式体现；写实关注触感、重量感、光线与行动的可信度；治愈来自保障、选择和可重新开始的余地；科幻通过新材料、移动城市、交通、生态与日常能力被看见。

长洲的园居是当地文化选择，不能推广为全人类必须采用的审美。有自我的人工生命保留自己的形态与喜好，机器可以精密而温柔，旧物也不天然优于新物。

画面保留青春、活力、诙谐和生活痕迹：晾晒的布、暂未收好的工具、湿石阶、修补过的栏杆都可出现。居民会犯错、烦恼、误解，也有求助与修复的机会。希望不要求永久晴天、绝对整洁或人人始终微笑。

**现有角色保护：**本次更新世界与美术总方向；已采用的人物身份、面容、服装款式、配色和素材保留，按[制作进度](../制作进度.md)选择当前版本。真实材质、场景与光照先行探索，是否进一步调整人物写实程度需通过合景逐项决定，不自动改为真人面孔。

## 三、云质：城市的承载与生长环境

### 3.1 已纳入的能力

“云质”为本卷描述特殊材料的暂用词，不是已经定名的物质或产品。它呈云的轻盈与流动形态，允许植物直接扎根生长。作者进一步确定：云质随能量注入与调控改变软硬／结构刚性，改变状态无需增加材料，自身质量在日常工程尺度下基本不变；下层形成稳定承托，上层可以柔软。

**2026-10-14 后续决定：材料与反重力技术配合。**云质负责承托建筑、分散载荷、组织形态及植物生长环境；反重力系统提供抵抗重力的悬浮支撑，承担云质、建筑、水、植物与居民等全部负载。材料变硬本身不产生升力，也不抵消所承载物体的重量。反重力是本作明确采用的虚构技术，不称为现实已实现或已验证的科学。

两项能力可共同部署和供能，但调节云质软硬与控制悬浮是不同功能。整城平移、转向与停靠的推进方式另待设计，不从反重力一词直接推出；也不自动取消惯性、居民日常重力或既有人间能力界线。

承托城市的云质、普通水雾与全息虚景须在设计记录里分清：分别承担真实结构、气象／感官与影像表现。可以在视觉上连续融合，但全息影像不自动成为承重实体，普通雾气也不能随意踩踏。云质不因可调节结构就自动具有自我或人格。

### 3.2 已定材料规则下的结构方案与未决参数

下层较硬、上层较软是城市的基本结构方向；具体设计可在建筑和道路下局部加固，园院边缘舒展流动，根系附近疏松多孔，避免把全部上层都理解为无法站稳的软面。水分、养分与空气输送方式继续设计。局部空间重组只作为候选能力，尚未确定庭院能够任意拆分或即时移动。

软硬可调与反重力悬浮的分工已定；内部组成、控制方式、能量供应、反重力具体机理、作用范围、承载上限、转换速度及维持能耗仍待设计。断能后的保持时间与冗余保障尚未定案，不能直接把“一断电就散城”或“永久无耗能”写成规则。城市运行须与现有能源和工具保障相容，不引入无穷能量、超光速、空间传送或无限材料复制。

### 3.3 人的触感与种植自由

可探索柔韧云面、擦过手背的浮絮、使睫毛沾湿的水雾等不同触感，让观众逐渐理解哪里能站、哪里能穿过、哪里有植物。具体触感尚待视觉与动作设计。

居民可用云质、真实泥土或两者结合养花种菜；住处仍适用既有使用权制度。无需土地作为承载基础不等于世界没有泥土、石头、地面荒野或种植活动，也不取消人物对翻土、土香与真实生长过程的喜爱。

## 四、立体园城与可居住的空间

生活园、匠作园、学园和园中园继续存在，以桥、廊、水巷、云间航路和垂直交通相连。布局从水系、台地高差、光照和生活联系生长；重庆只提供立体空间启发，不照搬现实城区、建筑或交通制度。

设计时允许多高度地面与入口：桥的一头是街面，另一头连接另一园院中层；屋顶花园可能与邻区步道齐平；上层步道旁的小溪，到下层成为水榭旁的瀑布。同一处建筑、植物和水景能从多个高度重新被看见。

**留空与通达：**密实建筑之间留出贯穿多层的天井、云隙、水庭与采光面，避免上层遮蔽全部下层。低处同样拥有明亮舒适的生活，不按高度划分人的价值。赏景曲径与高效直达路径并存，照顾不同身体与行动方式；不强迫所有人爬台阶、走迷宫或慢行。

**城市辨识：**可用主水脉、桥、树和显著公共场所帮助居民认路。云可改变视野，但邻里、地址与日常通路有稳定性；迁行不表示居民的家每天在城内随机换位。

**建筑的时间层次：**半园保留木石瓦、旧物和修补痕迹；新建学园可探索轻盈结构、较大开口和新材料，延续庭院与借景的组织方式。不要把全城做成同一时期、同一种尺度的古建展馆。

**半园的两岸生活（2026-10-14作者决定）：**生活园和修复作坊分设水巷两岸，让工作与居住分开，以桥、沿水步道联系。水巷既是景观，也是走向作坊与回家的日常空间。作者认可空间概念首稿中的对岸作坊，优先于旧v0.3“院内东坊”草模；桥位、尺度、包裹接收位置与原院内工坊体量的新用途仍待设计，不因概念图而视为工程或航路已验证。

## 五、园林手法怎样成为未来日常

| 手法 | 长洲的设计方向 |
|---|---|
| 借景、框景 | 小院、漏窗与廊口借入云海、远山、别处园院和星空；整城迁行使同一窗口的远景变化 |
| 移步换景 | 墙、树、云带、高差与转角共同组织显露；可先闻琴声、水声，再看见水榭与人 |
| 虚实结合 | 实体建筑、水与植物结合全息远景、倒影、帘影、声音和留白，不要求每处虚实关系都用投影 |
| 叠山理水 | 台地、云园、空中庭院、溪流和叠水共同安排高差、行动和视线 |
| 小中见大 | 熟悉小院通过借景与远方联系容纳更广阔的天地，保留少量关键联系与足够留白 |
| 亭榭与廊下停留 | 提供不必消费的休息、等人、看雨与独处场所，让开敞热闹与安静围合的空间可供选择 |
| 四时与养护 | 保留花期、落叶、雨雪、植物成长和日常修补，让技术保障下的生活仍有时间感 |

**云有疏密。**云雾可像变化的园墙，穿行于园与园之间、桥下、云岸及局部庭院。近处的人物、衣料、脚下路径与重要动作应清楚可见；城市也有大段晴朗、开敞空间。所有镜头都浓雾笼罩，会削弱穿云而出的变化。

**全息有来源。**借入异地实时景象时仍有真实传输时延；来自远方星海的影像不能被写成无延迟直播。全息仿真、记录影像和真实环境要在创作记录里注明，不混同万境、归墟，不改变意识与人格规则。

## 六、水系与基础设施景观

雨水可沿屋檐汇入浅渠，经过种植庭院，利用高差形成叠水，最后进入池塘或水巷。可接近的水景使用洁净或经过相应处理的水；生活污水有独立收集和处理路径，不能把普通污水直排成供人亲近的溪流。

根据场景设计雨水收集、储水、净化、回用和循环的关系。瀑布有收水与回水去向，不把水无止境倾倒到下层住宅或地面。晴天细流、雨后丰沛及水声渐小可成为时间与行动线索，具体水量不在本轮确定。

一条水脉可以串联学园水庭、植物园、叠水与码头，兼顾植物生长、行走、停留与城市辨识；不是每条溪流都必须承担全部工程任务。

## 七、交通：筋斗云、画舫与人的节奏

- **个人按需出行：**筋斗云意象，接续“飞的”的功能。云座的承托、坐姿、边界、舒适性和不同身体的使用方式继续设计；不自动规定翻筋斗动作或神话速度。
- **公共交通：**云上小舟／画舫意象，成为日常公交。可从古船提炼船舷、篷顶、廊窗与层次，结合未来结构；不要求整体照搬古船。不同高度的码头连接园院。
- **其他出行：**步行、曲桥回廊、水巷船、垂直交通与城际云舟可并存。乘画舫、步行、快速到达都可自选，具体线路不默认按城市环路组织。
- **费用与身份：**自动基本交通继续免费；真人同行按既有自愿约定，不暗示只有真人才能提供体贴服务。载具是否有自我不得只凭外观推断。
- **首集配送：**此前确认的无人机稳定携带舞鞋包裹仍有效；本次乘客交通意象不自动替换首集配送方式。

## 八、云生生态与园艺

云生植物直接在特殊云质中生长，有适应该环境的根、叶、花或繁殖方式。稀奇外形应与它如何获得水分、养分、光和依附位置相关。云间存在可被发现的小环境，穿行时可以遇到不同于土植园林的生命景观。

**以下五种为已保存的创作候选，名称、性状、来源均待选定，不作为已确认图鉴：**

| 暂名 | 候选生长方式 | 候选观看体验 |
|---|---|---|
| 垂根云树 | 树冠在园台上，长根穿过云层垂下 | 上层看树冠，下层经过根林 |
| 雾囊花 | 半透明囊状组织收集水滴，随蓄水低垂 | 先遇见一滴水，再在云中看见花 |
| 游絮草 | 小片植株依附轻薄云团迁移，适宜处扎根 | 昨日在窗外，今日停到桥边 |
| 听风藤 | 薄片叶随气流发出轻微声音 | 尚未看见园子，先听出一段廊桥的位置 |
| 隙光苔 | 在云层内有散射光的空隙生长 | 拨开薄云，发现柔和色泽的小世界 |

物种是自然适应、培育或其他来源尚未决定，不由奇异性状推定人工创造了有自我的生命，不改变现有生命边界。云生植物与江南原有花木、真实泥土种植并存；半园保留一块土种园地是候选场景，尚未锁定平面。

## 九、整城迁行与流动借景

整座长洲可以缓慢漂移、迁行，家、街巷、园院和日常关系随城同行。江南文化根脉保留；在太湖—运河区域停留时可俯瞰相应地景，离开后窗外按实际位置变化。旧苏州仍在大地原处，不能随着长洲一起移动。

迁行使“借景”延伸到城市尺度：同一扇窗、同一池倒影和熟悉的植物，可映照不同山水与天空。四季分明、舒适与无灾害的生活保障继续成立；路线不自动取消季节或强制追逐某一种天气。

长时间停留与缓慢迁行交替、居民期待下一处风景，是可继续发展的节奏方案。路线、速度、停留时间、调度方式、与其他城市的关系，以及固定轨道设施／天梯怎样衔接均待定。不能因城能移动就把天梯写成任意拖行的构件。

**保留的生活候选：**启程前看最后一次落日；两城临时连接云桥探访；画舫接驳附近目的地；远行者根据更新位置归家；孩子画初见的山、老人认出旧游之地；云园随经过环境出现花期与叶态变化。它们不自动变成普遍制度或首集情节。“归家”限于普通旅行，不取消主设定中人生道路“远行／远征”的特殊规则。

- 知夏沿溪走过廊街，下到另一层时，刚才脚边的水已成为身后水榭的银帘，桥上有人招手。
- 知夏在真实泥土里种植，墙外垂下云生植物的长根。
- 傍晚收工具、邻家做饭；镜头越过院墙、水巷和画舫，显出整座灯火温柔的云城正从群山间缓缓驶出。

## 十一、后续设计与制作衔接

先用学园、云桥、画舫站、水巷与半园的一段关系，探索高低剖面、步行体验与水流去向；这是推荐的设计入口，不自动替换已确认首集配送路线。确定场景后，再校准旧空间草案的承托结构、入口、航线和视线。

本轮未生成场景、植物、载具图片或视频，未制作新平面、模型或试飞；旧场景参考和灰模保留，其以旧条件完成的检验不能直接算作新云城已验证。半园的阿姐赠园关系、主体制度与第一季剧情沿用主设定。实际资产与ToonFlow回填状态另记制作进度。
